# 飞书多维表格 (Bitable) 接入与自动化指南
## 摘要
本指南用于指导完成飞书多维表格的接入配置，以实现AI课堂的学生数据统计与自动化流程，涵盖表格结构设计、开放平台权限配置、自动化场景搭建及核心参数获取四部分内容。

## 1. 飞书多维表格基础配置
### 1.1 数据表结构设计
需创建名为「AI 课堂学生成绩统计」的数据表，核心字段定义如下：
| 字段名           | 类型  | 说明                        |
| :------------ | :-- | :------------------------ |
| **学生姓名**      | 文本  | -                         |
| **飞书 OpenID** | 文本  | 用于私聊推送 (通过 OpenClaw 自动填入) |
| **课程名称**      | 选项  | -                         |
| **测验得分**      | 数字  | 由 OpenMAIC 回传             |
| **签到状态**      | 复选框 | -                         |
| **学习进度**      | 百分比 | -                         |
| **最后活跃时间**    | 日期  | -                         |

### 1.2 报名表单创建
1. 在目标多维表格中添加「表单视图」
2. 发布表单后，学生提交的报名信息将自动同步为表格新记录

## 2. 飞书开放平台配置
### 2.1 权限申请
需在飞书开放平台为应用申请以下权限：
- `bitable:app`：查看和管理多维表格数据
- `im:message`：发送飞书私聊消息
- `contact:user.employee:readonly`：只读读取员工基础信息

### 2.2 事件订阅
需订阅 `bitable.app.record.created_v1` 事件，使 OpenClaw 可监听到学生报名的新记录创建事件，触发后续自动化流程。

## 3. 自动化场景示例
### 3.1 报名成功自动邀请
- 触发条件：多维表格产生新报名记录
- 执行操作：OpenClaw 调用 OpenMAIC 接口生成课程链接，向对应学生飞书账号私聊推送

### 3.2 成绩达标自动发证
- 触发条件：测验得分字段更新且分值大于 80 分
- 执行操作：通过飞书原生自动化流向学生发送定制化证书图片

## 4. 核心参数获取
对接自动化工具所需的`APP_TOKEN`与`TABLE_ID`可从多维表格浏览器地址栏提取，地址格式为：
`https://feishu.cn/base/[APP_TOKEN]?table=[TABLE_ID]`
提取后需将两个参数填入 OpenClaw 的 `feishu` 插件配置项中。
