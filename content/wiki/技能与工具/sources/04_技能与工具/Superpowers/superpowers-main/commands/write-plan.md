# write-plan 命令
## 摘要
`write-plan` 是 Superpowers 工具集中用来生成详细落地方案的命令，核心作用是拆分出可执行的小型任务。

## 关键要点
- 功能定位：创建带有细分小型任务的详细实现计划
- 配置属性：禁用了模型调用功能
- 执行要求：需要调用 Superpowers 的 `writing-plans` 技能，并严格按照技能给出的规则执行
