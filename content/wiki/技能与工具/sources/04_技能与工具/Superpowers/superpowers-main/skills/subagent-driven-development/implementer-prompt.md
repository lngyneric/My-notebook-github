# 执行器子代理提示模板
## 摘要
执行器子代理提示模板（Implementer Subagent Prompt Template）是向执行器子agent分派开发任务时使用的标准化提示模板，规范了任务派发时需要向子agent传递的信息、工作要求和交付规范，用于指导执行器子agent完成指定的代码实现工作。

## 关键要点
1.  模板面向执行器子agent，明确了任务描述、上下文、开工前要求、工作内容、自我审查要求和最终汇报格式等模块。
2.  要求子agent在开工前如果对需求、方案、依赖等内容有疑问，必须先提出澄清，不得猜测假设。
3.  明确了标准工作流程：按要求实现 → 编写测试 → 验证功能 → 提交代码 → 自我审查 → 汇报结果。
4.  自我审查从完整性、代码质量、开发规范、测试质量四个维度展开，要求子agent自查后修复问题再交付。
5.  最终汇报要求明确包含实现内容、测试结果、修改文件、自查结果和现存问题。

## 模板结构说明
| 模块 | 内容说明 |
|------|----------|
| 任务描述 | 粘贴任务计划中的完整任务文本，不需要子agent自行读取文件 |
| 上下文 | 说明任务的位置、依赖关系、架构上下文 |
| 开工前要求 | 要求子agent对所有不明确的内容提前提问澄清 |
| 工作内容 | 明确子agent的六步工作流程，指定工作目录，要求工作中遇到问题及时暂停澄清 |
| 交付前自我审查 | 从四个维度规定了子agent的自查标准：<br>1. 完整性：是否覆盖所有需求、处理边界场景<br>2. 质量：代码是否清晰可维护、命名准确<br>3. 开发规范：避免过度设计，仅实现需求内容，遵循现有代码模式<br>4. 测试：验证实际行为、遵循TDD要求、覆盖全面 |
| 汇报格式 | 规定最终输出需要包含的内容项 |
