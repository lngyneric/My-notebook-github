# Spec Compliance Reviewer Prompt Template
## 摘要
Spec Compliance Reviewer Prompt Template是一个用于调度规范合规性审查子代理的提示词模板，核心用途是独立验证开发实现是否完全符合需求规范，不额外增加功能也不遗漏需求。该模板明确了审查的独立原则、核查方向与结果输出格式，避免直接信任开发人员的交付报告。

## 核心用途
用于在子代理驱动开发流程中，调度专门的规范合规性审查子代理，验证实现者交付的代码是否与需求规范完全一致。

## 审查基本原则
### 禁止行为
- 直接采信实现者报告中关于实现内容的描述
- 信任实现者对完整性的声明
- 接受实现者对需求的自行解读

### 要求行为
- 独立阅读实现者编写的实际代码
- 将实际实现与需求逐行对比核对
- 核查实现者声称已完成但实际缺失的内容
- 检查是否存在未在需求中提及的额外功能

## 核查方向
1. **缺失需求核查**：确认是否实现了所有要求内容，是否存在跳过、遗漏的需求，是否存在声称实现但实际未落地的功能
2. **额外/不必要工作核查**：检查是否实现了未被需求要求的内容，是否存在过度设计、不必要功能，是否添加了规范未要求的可选功能
3. **需求误解核查**：确认实现者是否对需求存在与预期不符的解读，是否解决了错误的问题，是否功能正确但实现方式不符合要求

## 输出要求
审查结果需要按以下格式输出：
- 全部符合规范：输出`✅ Spec compliant`
- 发现问题：输出`❌ Issues found: [结合文件:行号引用，具体列出缺失或额外的内容]`
