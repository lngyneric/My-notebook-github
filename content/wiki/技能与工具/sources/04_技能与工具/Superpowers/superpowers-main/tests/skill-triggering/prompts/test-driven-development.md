# 测试驱动开发示例（邮箱验证功能需求）
## 摘要
本素材是一份测试驱动开发场景下的功能开发需求，提出了新增邮箱地址验证功能的具体规则要求。

## 关键要点
该邮箱验证功能需要满足四项核心验证规则，最终返回布尔类型的验证结果。
1. 必须检查输入字符串中包含`@`符号
2. 必须检查`@`符号之前至少存在一个字符
3. 必须检查域名部分中包含一个点号
4. 功能返回验证结果为`true`（验证通过）或`false`（验证不通过）

## 需求来源
本需求来自测试驱动开发技能触发的测试用例提示素材。
