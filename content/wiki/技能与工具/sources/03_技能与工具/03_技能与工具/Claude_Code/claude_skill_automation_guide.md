# Claude Agent Skills 自动化“万能公式”操作指南
> 来源路径：`raw/03_技能与工具/Claude_Code/claude_skill_automation_guide.md`

---

## TL;DR
本指南基于「人人可用的自动化」理念，只需要三步即可将任意Web操作转化为Claude AI可调用的技能，核心流程为：通过浏览器开发者工具复制目标操作的cURL请求，交给AI生成可调用的Skill，最后放入指定目录即可用自然语言调用。

---

## 核心要点
1.  **核心公式**：浏览器F12复制cURL + Skill Creator 即可全自动生成AI可调用的Skill
2.  不需要提前准备API文档，仅用浏览器即可获取自动化需要的所有请求信息
3.  标准Skill包含`SKILL.md`（技能说明与触发定义）和`script.py`（执行逻辑）两个核心文件
4.  生成后放入`.trae/skills/`目录即可通过自然语言直接调用
5.  可通过参数化、增加错误处理、技能组合实现更通用稳定的自动化能力

---

## 实操步骤
### 第一步：获取数据源（无需API文档）
> [!NOTE] 证据片段：
> > 你不需要后端开发提供的 API 文档，只需要利用浏览器即可获取所需的请求信息。

操作流程：
1.  在Chrome浏览器中打开目标网页（例如：库存查询页、表单提交页）
2.  按`F12`或右键选择「检查」开启开发者工具，切换到**Network (网络)**标签页
3.  在网页上触发一次你想要自动化的操作（例如：点击「查询」按钮）
4.  在Network列表找到对应的请求（通常为Fetch/XHR类型），右键 -> 选择**Copy** -> **Copy as cURL (bash)**，复制请求信息

---

### 第二步：自动化生成Skill
操作流程：
1.  在Claude/Trae中调用Skill Creator（技能生成器）
2.  输入指令：
    > "请帮我创建一个名为 `[技能名称]` 的 Skill。核心逻辑是以下 cURL 命令，请将其封装为 Python 脚本，并生成对应的 SKILL.md。"
3.  粘贴第一步复制的cURL内容
4.  等待AI自动分析请求信息，生成包含`SKILL.md`和`script.py`的完整Skill文件夹

---

### 第三步：安装与使用
操作流程：
1.  将生成的Skill文件夹放入`.trae/skills/`目录完成部署
2.  直接用自然语言调用（例如：“帮我查询一下 [参数] 的数据”），AI会自动匹配技能、运行脚本返回结果

---

## Skill 结构解析
| 文件 | 说明 | 作用 |
| :--- | :--- | :--- |
| **SKILL.md** | 核心说明书 | **YAML 头**：定义技能名称和触发条件（AI 靠这个识别技能）。<br>**正文**：操作指南，告诉 AI 何时以及如何使用脚本。 |
| **script.py** | 执行脚本 | 包含具体的 API 调用逻辑（由 cURL 转换而来），处理数据请求与响应。 |

---

## 进阶技巧
> [!NOTE] 证据片段：
> *   **参数化**：在生成 Skill 时，要求 AI 将 cURL 中的固定值（如查询关键词、日期）提取为 Python 脚本的输入参数，这样技能就通用了。
> *   **错误处理**：让 AI 在脚本中增加对 HTTP 错误码（4xx, 5xx）的处理逻辑，提高稳定性。
> *   **组合使用**：你可以生成多个小的 Skill（如“查询数据”、“发送邮件”），然后通过自然语言让 AI 将它们串联起来工作。
