# 图增强检索概述
本页编译自 `raw/04_文档与参考/Markdown文档/注意.md`

## TL;DR
传统检索增强生成（RAG）依赖基于非结构化文本的向量搜索，仅能处理语义相似度场景，无法有效捕捉社交网络中的关系结构、社区拓扑和影响力传播的多跳路径；要分析社交网络中的影响力与信息流动，需要将图结构直接融入检索流程。

## 要点
1. 理解社交网络中的影响力和信息流动，不能仅靠提取文本片段或孤立文档实现
2. 传统检索增强生成（RAG）流程依赖非结构化文本上的向量搜索
3. 向量搜索对语义相似度匹配场景表现良好，但会忽略关系结构、社区拓扑和多跳传播路径
4. 要对社交图进行有意义的分析，AI系统需要将图结构直接整合到检索过程中
