## 要点
### 选择 Obsidian 的核心理由
1. **数据安全**：笔记为本地纯 Markdown 文件，不依赖软件服务，软件停运也不会丢失数据
2. **流畅体验**：UI 响应速度快，无卡顿白屏，保护工作心流
3. **AI 适配性好**：原生支持本地文件，可直接对接 Claude Code、Gemini CLI 等 AI 工具，实现笔记处理、文风仿写等能力

### 云同步方案：GitHub
| 步骤 | 操作要点 |
|------|----------|
| 1. 创建仓库 | GitHub 新建私有(Private)仓库，保护笔记隐私 |
| 2. 克隆本地 | 使用 GitHub Desktop/命令行克隆仓库，在 Obsidian 中打开该文件夹作为 vault |
| 3. 配置忽略 | 根目录添加 `.gitignore`，排除多端冲突的工作区文件：<br>`.obsidian/workspace.json`<br>`.obsidian/workspace-mobile.json` |
| 4. 自动化同步 | 安装 `Obsidian Git` 社区插件，开启编辑后自动提交同步，设置1分钟间隔，开启启动自动拉取 |

### AI 玩法：Gemini CLI 实战
1. 环境准备：安装 Node.js → 通过 `npm install -g @google/gemini-cli` 安装 Gemini CLI → 运行 `gemini` 完成 Google 账号授权
2. 常用场景：
   - 选题生成：读取历史笔记/脚本，分析风格后生成新选题并输出为 Markdown
   - 批量整理：根据大纲自动创建文件夹结构，完成归档整理
   - 脚本仿写：搜索热点内容，模仿用户个人笔记文风生成内容
3. 安全保障：使用 Git 管理笔记，AI 修改错误可随时回滚到修改前状态

### Markdown 基础语法
| 语法 | 格式 |
|------|------|
| 标题 | `# 一级标题` `## 二级标题` 依此类推 |
| 加粗 | `**加粗内容**` |
| 删除线 | `~~删除内容~~` |
| 高亮 | `==高亮内容==` |
| 代码块 | ```` ```语言名称 内容 ``` ```` |
| 引用 | `> 引用内容` |
| 无序列表 | `- 列表项` |
| 有序列表 | `1. 列表项` |
| 其他 | 右键可插入表格、分割线、LaTeX 数学公式 |

### 图片存储优化
使用 `Custom Attachment Location` 插件解决默认存储的目录混乱、GitHub 不兼容问题：
1. 插件配置：
   - 新附件位置：选择当前文件夹下的子文件夹，或指定统一 assets 目录
   - Markdown 链接格式：设置为 `![${name}](${path})` 生成标准格式
   - 开启附件自动重命名
2. Obsidian 全局设置：
   - 内部链接类型选择**基于当前笔记的相对路径**
   - 关闭「使用 Wiki 链接」
3. 效果：自动归类图片，移动笔记时附件自动跟随，GitHub/VS Code 可正常预览；支持 `![image|300](path.png)` 语法调整图片宽度

### 手机端同步
1. 先通过数据线将本地仓库复制到手机（推荐存放于 `Documents` 目录）
2. Obsidian 手机端选择「打开文件夹作为 vault」
3. 启用 Obsidian Git 插件，配置 GitHub 用户名、邮箱，填入 GitHub 生成的 Personal Access Token（需勾选 repo 权限）
4. 注意事项：避免多端同时编辑同一文件，减少合并冲突

### 导出与知识图谱
1. 导出 Word/HTML：安装 `Enhancing Export` 插件，配置 Pandoc 后即可右键导出
2. 双向链接与图谱：使用 `[[笔记标题]]` 创建双向链接，可通过关系图谱可视化笔记关联，激发灵感

> [!SUMMARY] 教程简介
> 本教程涵盖了从云同步、图片存储、手机端使用到 AI 玩法等 Obsidian 高级使用技巧。方案特点：全套工具免费，偏向极客与程序员风格，旨在解决数据安全、多端同步与 AI 辅助创作需求。

> 我有三个必须使用 Obsidian 的理由：
> 1.  **数据安全**：笔记本质上是本地电脑上的独立 Markdown 文件。即使软件开发者跑路，笔记也不会丢失，换个编辑器即可。
> 2.  **丝滑流畅**：UI 响应速度极快，没有白屏和卡顿，保护工作心流。
> 3.  **AI 工具绝配**：Claude Code、Gemini CLI 等 AI 编程工具天生擅长处理本地 Markdown 文件，可以实现查找笔记、整理文件夹、仿写文风等神奇用法。

> [!TIP] 数据安全
> 使用 Git 管理笔记的好处是，如果 AI 改乱了文件，可以随时 `Discard changes` 回滚到修改前的状态。
