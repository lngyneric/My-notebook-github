# 希森美康（SCH）组织架构总览

## 摘要
本文基于公司最新组织架构图，梳理了从总经理到各一级、二级部门直至办事处/课级单位的层级关系。组织架构呈现典型的职能型与区域型混合结构，销售本部、市场营销部、客户服务本部等核心业务线均设有高级总监或副总经理，并向下细分区域与功能小组，同时包含财务、人力资源、供应链、战略分析等支持部门。

## 关键要点
- **最高层**：总经理直接管理18个一级部门/室，涵盖销售、市场、服务、学术、注册法规、财务、人力、供应链、战略、法务、监察、企画等。
- **销售体系**：销售本部由常务副总经理负责，下设销售一部和销售二部。销售一部再划分为5个大区，每个大区管辖若干省市办事处；销售二部则分为两个区。
- **市场营销部**：负责血液、凝血、综合产品三大产品课。
- **客户服务本部**：下设客户服务部（按东、南、西、北、中五区覆盖全国）和IT管理部（包括内部AI开发和外部AI开发运维）。
- **学术/应用本部**：分为南区（4个课+生命科学应用课）和北区（4个课）。
- **各部门独立设置**：BD事业部、注册法规&品保本部、生化免疫事业部、市场执行部（大客户经理团队）、财务本部、人力资源行政部、供应链管理部、战略分析管理部、法务合规部、监察室、经营企画室、总经理秘书室。

## 证据片段（结构关系示例）
- 总经理 → 销售本部（常务副总经理） → 销售一部（总监） → 销售一区（高级总监） → 北京办事处、山东办事处、沈阳办事处、河北办事处
- 总经理 → 客户服务本部（高级总监） → 客户服务部（高级总监） → 客服东区（高级经理）、客服南区（高级经理）、客服西区（经理）、客服北区（经理）、客服中区（经理）、技术课（经理）、客服综合管理课（高级经理）、服务营销课（高级经理）
- 总经理 → IT管理部（总监） → 内部AI开发（经理）、外部AI开发及运维（高级经理）
- 总经理 → 市场执行部（总监） → 大客户经理团队（副总监） → 5个大客户经理小组

## 重要备注
- 组织图采用Mermaid语法绘制，各层节点有颜色区分。
- 部分职位写有“代理总监/经理”“高级总监”“副总监”“高级经理”等职级，反映实际任职状态。
- 销售一区和二区覆盖全国主要省市，具体办事处列表已包含北京、上海、山东、浙江等关键区域。
