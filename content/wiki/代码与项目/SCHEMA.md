# 代码与项目 维基领域规范

## 概述
实际代码项目、脚本工具、示例数据

## 目录结构

```
wiki/代码与项目/
├── entities/   # 实体（TypeScript项目, React应用, CLI工具, API服务）
├── concepts/   # 概念（前端开发, 后端架构, 测试驱动, 部署运维, 版本控制）
├── summaries/  # raw/ 源文件摘要
├── sources/    # 源文件处理记录
├── SCHEMA.md   # 本领域规范
├── index.md    # 领域索引
└── log.md      # 操作日志

raw/代码与项目/  # 不可变源文件
```

## 页面类型
- **entities/** — 人、组织、系统、项目、工具
- **concepts/** — 理论、方法、模型、模式
- **summaries/** — 源文件摘要（LLM 生成）
- **sources/** — 源文件处理记录

## 交叉引用规范
- 使用 `[[页面名]]` 格式
- 跨领域引用: `[[领域/页面名]]`
- 源文件: `source: 文件名`
