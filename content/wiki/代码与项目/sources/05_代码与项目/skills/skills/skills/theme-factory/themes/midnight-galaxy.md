# Midnight Galaxy 主题

> [!NOTE] 来源
> 路径：`raw/05_代码与项目/skills/skills/skills/theme-factory/themes/midnight-galaxy.md`

## TL;DR
Midnight Galaxy 是一款偏宇宙戏剧风格的演示主题，以深紫色系神秘色调为核心设计，适合娱乐、游戏、高端品牌类演示场景。

## 要点
### 基础风格
这是一款富有戏剧感的宇宙风主题，采用深紫色和神秘色调打造，适合打造视觉冲击力强的演示内容。

### 颜色配置
| 色号 | 颜色名称 | 用途 |
| ---- | -------- | ---- |
| `#2b1e3e` | Deep Purple（深紫色） | 深色基底 |
| `#4a4e8f` | Cosmic Blue（宇宙蓝） | 神秘中调 |
| `#a490c2` | Lavender（薰衣草紫） | 柔和强调色 |
| `#e6e6fa` | Silver（银色） | 高亮、文字使用 |

### 排版配置
- 标题：FreeSans Bold
- 正文：FreeSans

### 适用场景
适合娱乐行业、游戏演示、夜生活场所、奢侈品牌、创意机构使用。
