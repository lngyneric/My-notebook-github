# Sunset Boulevard
> [!INFO] 来源：`raw/05_代码与项目/skills/skills/skills/theme-factory/themes/sunset-boulevard.md`

## TL;DR
Sunset Boulevard 是一款受黄昏黄金时刻启发的主题工厂主题，风格温暖活泼，适合活力、创意类展示场景。

## 要点
- 设计风格：温暖活泼，灵感来源于黄昏黄金时刻
- 定位：适合充满活力与创意的演示内容
- 配色方案：
  | 色彩名称 | 色值 | 用途 |
  | --- | --- | --- |
  | Burnt Orange | `#e76f51` | 主强调色 |
  | Coral | `#f4a261` | 次要暖调强调色 |
  | Warm Sand | `#e9c46a` | 高亮与背景 |
  | Deep Purple | `#264653` | 深色对比与文本 |
- 排版规范：
  - 标题：DejaVu Serif Bold
  - 正文：DejaVu Sans
- 适用场景：创意推介、营销演示、生活方式品牌、活动推广、励志内容
