# Golden Hour 主题

> [!NOTE] TL;DR
> Golden Hour 是一个以秋季暖调为风格的设计主题配色方案，整体氛围温暖浓郁，适合餐饮、秋日活动、生活方式类内容使用。

## 基本介绍
Golden Hour 是一个浓郁温暖的秋季风格调色板，能够营造出有吸引力的精致氛围。

## 核心要点
### 颜色配置
| 颜色名称 | 色值 | 用途 |
| ---- | ---- | ---- |
| 芥末黄（Mustard Yellow） | `#f4a900` | 主要强调色 |
| 赤陶色（Terracotta） | `#c1666b` | 次要暖调色 |
| 暖米色（Warm Beige） | `#d4b896` | 中性背景色 |
| 巧克力棕（Chocolate Brown） | `#4a403a` | 深色文本与锚点 |

### 排版配置
- 标题：FreeSans Bold
- 正文：FreeSans

### 适用场景
适合餐厅展示、 hospitality 品牌、秋季活动推广、舒适生活方式内容、手工匠人产品使用。
