# Desert Rose 主题

> [!NOTE] 本文基于原始资料编译，原始内容未做修改

---

## TL;DR
Desert Rose 是一款色调柔和素雅的主题，以暗哑低饱和色调为特色，非常适合优雅风格的演示场景。

---

## 要点

### 基本定位
柔和精致的主题，采用暗哑低饱和色调，适配优雅演示场景。

### 配色方案
| 色号名称 | 色值 | 用途 |
| ---- | ---- | ---- |
| Dusty Rose | `#d4a5a5` | 主色调，柔和 |
| Clay | `#b87d6d` | 大地风强调色 |
| Sand | `#e8d5c4` | 暖中性背景 |
| Deep Burgundy | `#5d2e46` | 浓郁深色对比度 |

### 排版
- 标题：FreeSans Bold
- 正文：FreeSans

### 适用场景
最佳适用场景包括：时尚演示、美妆品牌、婚礼策划、室内设计、精品商业。
