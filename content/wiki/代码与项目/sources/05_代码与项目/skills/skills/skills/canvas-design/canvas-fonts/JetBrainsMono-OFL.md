# JetBrainsMono SIL Open Font License 说明

本页记录 JetBrainsMono 字体携带的官方许可证全文。

> 来源路径：`raw/05_代码与项目/skills/skills/skills/canvas-design/canvas-fonts/JetBrainsMono-OFL.txt`

## TL;DR
JetBrainsMono 字体基于 **SIL Open Font License 1.1** 授权，允许自由使用、研究、修改和分发，仅需满足几个核心限制：
1. 字体本身不能单独售卖，可和其他软件捆绑分发售卖
2. 衍生版本（修改版）不能使用原字体的保留名称，除非获得原版权方书面许可
3. 无论是原版还是修改版字体，都必须继续使用本协议分发，不能更换其他许可证
4. 用本字体生成的文档不属于字体本身，不受本协议限制

## 要点
| 授权项 | 规则 |
|--------|------|
| 个人/商用使用 | ✅ 允许 |
| 修改 | ✅ 允许 |
| 分发 | ✅ 允许 |
| 捆绑进软件售卖 | ✅ 允许 |
| 字体单独售卖 | ❌ 禁止 |
| 修改版更换许可证 | ❌ 禁止 |
| 修改版使用原保留字体名 | ❌ 禁止（除非获得原版权方书面许可） |
| 用该字体创作的文档版权限制 | ✅ 不受本协议限制 |
