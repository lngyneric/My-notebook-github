# Erica One 字体版权授权说明

## TL;DR
Erica One 字体由LatinoType Limitada持有版权，以**SIL Open Font License 1.1版本**授权开放使用，核心授权规则：
1. 可自由使用、修改、再分发字体本身，但不允许单独出售字体
2. 修改后的衍生版本不能使用保留字体名「Erica One」（除非获得版权方书面授权）
3. 字体本身（含修改版）必须始终遵循OFL 1.1授权，不能改用其他协议
4. 使用该字体创建的文档/作品不受本授权约束，可自由商用、闭源
