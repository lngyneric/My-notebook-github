# Crimson Pro 字体 SIL Open Font License 1.1 授权说明

> 本页整理自 `raw/05_代码与项目/skills/skills/skills/canvas-design/canvas-fonts/CrimsonPro-OFL.txt` 原始授权文件

## TL;DR
Crimson Pro 字体基于 **SIL 开放字体许可证 1.1 版**发布，允许你免费使用、研究、修改和重新分发字体，但有几个核心限制：
1. 字体本身（含修改版）不能单独出售，只能和其他软件捆绑分发售卖
2. 修改版字体不能使用原字体保留名称（除非获得原版权方书面授权）
3. 无论是否修改，字体本身必须始终沿用本许可证，不能更换其他授权协议
4. 使用该字体创作的文档本身不受本许可证约束

## 核心要点
| 项目 | 规则 |
|------|------|
| 允许行为 | ✅ 免费使用、研究、复制、修改、合并、嵌入、分发字体（含修改版）<br>✅ 字体（含修改版/衍生版）可随其他软件捆绑、分发、售卖<br>✅ 用本字体创作的最终文档可自由使用，不受本许可证限制 |
| 禁止行为 | ❌ 字体本身（原版/修改版/任意组件）不得单独出售<br>❌ 修改版不得使用原字体保留名称（除非获得原版权方书面授权）<br>❌ 不得将字体修改后更换为其他许可证发布<br>❌ 不得未经授权使用原版权方/作者名义宣传修改版字体 |
| 分发要求 | 分发时每份拷贝必须包含本版权声明和许可证文本 |
