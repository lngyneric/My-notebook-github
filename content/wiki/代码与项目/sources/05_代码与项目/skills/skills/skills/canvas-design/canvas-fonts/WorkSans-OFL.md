## TL;DR
WorkSans 字体采用 SIL Open Font License 1.1 授权，你可以免费使用、修改、分发这个字体，也可以把字体打包在任何软件中销售，只要不单独出售字体本身、修改版本不使用保留字体名、保留完整版权和授权说明，并且所有修改版本也必须继续遵守本协议即可。使用这个字体生成的文档不受本授权约束。

## 要点
1. **版权信息**
   - 版权归属：2019 Work Sans Project Authors，项目地址 <https://github.com/weiweihuanghuang/Work-Sans>
   - 授权协议：SIL Open Font License Version 1.1，官方地址 <https://openfontlicense.org>

2. **核心授权规则**
   - ✅ 允许：免费使用、学习、复制、修改、合并、嵌入、分发、销售修改/未修改版本的字体
   - ❌ 禁止：字体本身（含修改版本）单独出售
   - 📝 要求：
     1. 所有分发版本必须保留本版权声明和授权文本
     2. 修改版本未经原版权方书面许可，不得使用原保留字体名（仅限制对用户展示的主字体名）
     3. 不得未经许可使用原版权方/原作者姓名为修改版本背书宣传
     4. 字体（无论修改与否）必须始终以本协议分发，不得更换其他协议
   - ⚠️ 例外：使用本字体创作的文档本身不受本协议约束

3. **免责声明**
   字体软件按现状提供，不提供任何明示或暗示的担保，包括但不限于适销性、特定用途适用性的担保。原版权方不对字体使用过程中产生的任何索赔、损害承担责任。
