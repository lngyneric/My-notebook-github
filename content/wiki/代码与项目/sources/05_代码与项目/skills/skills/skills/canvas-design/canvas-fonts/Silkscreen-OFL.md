## TL;DR
Silkscreen 字体基于 **SIL Open Font License 1.1 (OFL-1.1)** 免费开源授权，可自由使用、学习、修改、分发，仅需要遵守几个简单条件：
1. 字体本身不能单独售卖，可和其他软件捆绑销售
2. 分发时必须保留完整版权和本授权信息
3. 修改后的字体不能使用原保留字体名，除非获得原作者书面授权
4. 修改版本不能用原版权持有人/作者名义宣传，除非获得授权
5. 字体本身无论修改与否都必须继续以本协议分发，不限制用该字体创作的文档的协议

| 规则分类 | 具体要求 |
|---------|---------|
| 允许行为 | 个人/商业免费使用、学习、修改、合并、嵌入、分发、售卖修改/未修改版本的字体 |
| 禁止单独售卖 | 字体本身（原始/修改版）不能单独作为商品售卖 |
| 分发要求 | 所有分发版本必须附带完整版权声明和本授权文本 |

| 署名限制 | 不得使用原版权持有人/作者名义宣传修改版本，除非获得授权或仅用于标注原贡献 |
| 协议继承要求 | 字体本身无论是否修改都必须始终以OFL-1.1分发，不得更换协议；**不限制使用该字体创作的文档/作品的协议** |
