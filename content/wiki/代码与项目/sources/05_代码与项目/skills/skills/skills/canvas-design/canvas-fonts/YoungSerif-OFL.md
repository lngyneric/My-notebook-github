# YoungSerif 字体 SIL Open Font License 1.1 授权说明

本页记录 YoungSerif 字体随附的完整开源字体授权文本。

---

## TL;DR
YoungSerif 字体采用 **SIL 开放字体许可证 1.1 版本** 发布，允许任何人免费使用、研究、修改、分发字体，核心规则：
1. 字体本身（含修改版）不能单独售卖，但可以和其他软件捆绑后售卖
2. 任何分发都必须保留原版权声明和本授权文本
3. 修改版字体不能使用原保留字体名称（除非获得原版权方书面授权）
4. 修改后的字体也必须使用本许可证分发，不能更换为其他协议
5. 用这个字体创作的文档本身不受本许可证约束

---

## 授权核心要点
| 规则分类 | 核心内容 |
|---------|---------|
| 允许行为 | 免费使用、学习、复制、修改、嵌入、再分发字体（含修改版），可以和任意软件捆绑销售 |
| 禁止行为 | 1. 字体本身（原版本/修改版）单独售卖<br>2. 修改版未经授权使用原保留字体名称<br>3. 修改后的字体改用其他授权协议<br>4. 未经许可用原版权方/原作者名称宣传修改版 |
| 特殊说明 | 本许可证仅约束字体软件本身，**不约束使用这个字体创作的文档/作品** |
| 免责声明 | 字体软件按「现状」提供，不提供任何明示或暗示的担保，版权方不对使用产生的任何损失负责 |
| 协议终止 | 只要违反上述任意条件，本授权自动失效 |
