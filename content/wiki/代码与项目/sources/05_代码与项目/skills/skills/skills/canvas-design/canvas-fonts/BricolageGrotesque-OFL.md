# Bricolage Grotesque 字体许可证

本页面记录 Bricolage Grotesque 字体的完整许可证信息。

## TL;DR
Bricolage Grotesque 字体基于 **SIL Open Font License 1.1（SIL 开放字体许可证 1.1 版）** 发布，允许免费使用、学习、修改、再分发，字体本身不能单独出售，修改后的版本不能使用原保留字体名，所有修改/未修改的字体文件必须继续沿用本许可证，用该字体创作的文档本身不受许可证约束。

## 许可证核心要点
1. **允许的行为**：任何主体都可以免费使用、研究、复制、合并、嵌入、修改、再分发、出售修改/未修改版本的字体软件
2. **核心限制**：
   - 字体软件本身（无论原始版本还是修改版本）不可以单独出售
   - 任何分发版本都必须附带本版权声明和许可证文本
   - 修改版本未经原版权方书面许可，不得使用原保留字体名称（该限制仅对面向用户的主字体名生效）
   - 不得未经许可使用原版权方/作者姓名为修改版本做宣传
   - 字体软件（无论修改与否）必须始终沿用本许可证，不得更换为其他许可证
3. **例外情况**：使用该字体创作的文档/作品本身不受本许可证的约束
