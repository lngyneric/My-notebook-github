# NationalPark 字体 SIL Open Font License v1.1

本页面存储 Canvas 设计项目使用的 NationalPark 字体的开源授权文本，来源为字体官方提供的授权文件。

## TL;DR
本字体基于 **SIL Open Font License 1.1** 授权，可免费使用、修改、分发，可免费或商用嵌入到软件/作品中，但禁止单独售卖字体本身，衍生修改版不能使用原字体保留名称，所有修改后的字体也必须继续沿用本授权，使用本字体创作的文档/作品不受本授权约束。

## 核心要点
| 条款 | 说明 |
|------|------|
| 授权允许的行为 | 可免费对原字体和修改字体进行使用、研究、复制、合并、嵌入、修改、分发、售卖 |
| 核心限制 | 禁止单独售卖字体软件本身（单独售卖其中任意组件也不允许） |
| 分发要求 | 所有分发的版本都必须附带本版权声明和本授权文本 |
| 保留名称限制 | 衍生修改版不能使用原字体的保留名称，除非获得原版权方书面授权 |
| 署名限制 | 不能用原版权方/原作者名义宣传衍生版本，除非获得书面授权 |
| 授权传染性 | 无论修改与否，字体软件本身必须始终使用本授权分发，不能改用其他授权 |
| 作品例外 | 使用本字体创作的文档/设计作品等输出内容不受本授权约束 |
| 免责声明 | 字体软件按「原样」提供，不提供任何明示或默示担保，版权方不承担使用带来的任何损失责任 |
