## TL;DR
本技能提供了对 `.pptx` 演示文稿进行创建、编辑、分析的完整工作流，涵盖**无模板新建**、**现有模板新建**、**现有演示文稿编辑**三种核心场景，定义了从内容提取、设计、排版到验证的标准化操作流程。

---

## 要点
1. **核心能力**：支持 `.pptx` 文件的文本/结构分析、从零新建演示文稿、基于现有模板创建演示文稿、编辑现有演示文稿
2. **内容提取分析**：普通文本提取用 `markitdown` 转换为markdown；需要评论、演讲者备注、版式等信息时需要解压获取原始XML
3. **无模板新建**：使用 `html2pptx` 工作流，要求先声明符合内容的设计方案，仅使用网页安全字体，优先使用双列或全幅布局，完成后生成缩略图验证视觉效果
4. **基于模板新建**：需先提取模板内容、生成缩略图、整理模板版式清单，再根据内容匹配版式，通过 rearrange 复制排序幻灯片，替换文本后生成新文件
5. **编辑现有文件**：解压获取原始OOXML，编辑后验证再重新打包
6. **依赖项**：需提前安装 markitdown、pptxgenjs、playwright、LibreOffice 等工具

## 详细文档

### 概述
当用户要求创建、编辑或分析 `.pptx` 文件内容时使用本技能。`.pptx` 文件本质是包含XML文件和其他资源的ZIP压缩包，可根据不同任务选择对应工具和工作流。

### 读取和分析内容

#### 文本提取
如果仅需要读取演示文稿的文本内容，可将文档转换为markdown：
```bash
# Convert document to markdown
python -m markitdown path-to-file.pptx
```

#### 原始XML访问
如果需要处理评论、演讲者备注、幻灯片版式、动画、设计元素、复杂格式，需要解压演示文稿并读取原始XML内容。

##### 解压文件
`python ooxml/scripts/unpack.py <office_file> <output_dir>`

**说明**：`unpack.py` 脚本位于相对于项目根目录的 `skills/pptx/ooxml/scripts/unpack.py`，如果该路径不存在脚本，使用 `find . -name "unpack.py"` 定位。

##### 核心文件结构
* `ppt/presentation.xml` - 主演示文稿元数据和幻灯片引用
* `ppt/slides/slide{N}.xml` - 单个幻灯片内容（例如 `slide1.xml`、`slide2.xml` 等）
* `ppt/notesSlides/notesSlide{N}.xml` - 各幻灯片的演讲者备注
* `ppt/comments/modernComment_*.xml` - 特定幻灯片的评论
* `ppt/slideLayouts/` - 幻灯片版式模板
* `ppt/slideMasters/` - 幻灯片母版模板
* `ppt/theme/` - 主题和样式信息
* `ppt/media/` - 图片和其他媒体文件

##### 字体和颜色提取
**当需要复刻示例设计时**：必须优先使用以下方法分析演示文稿的字体和颜色：
1. **读取主题文件**：检查 `ppt/theme/theme1.xml` 中的颜色（`<a:clrScheme>`）和字体（`<a:fontScheme>`）
2. **采样幻灯片内容**：检查 `ppt/slides/slide1.xml` 中的实际字体使用（`<a:rPr>`）和颜色
3. **搜索模式**：使用 grep 在所有XML文件中搜索颜色（`<a:solidFill>`、`<a:srgbClr>`）和字体引用

### 从零新建PowerPoint演示文稿（无模板）
从零创建新演示文稿时，使用 **html2pptx** 工作流将HTML幻灯片转换为PowerPoint，可实现精确定位。

#### 设计原则
**关键要求**：创建任何演示文稿之前，必须先分析内容并选择合适的设计元素：
1. **考虑主题**：演示文稿的主题是什么？需要什么色调、行业属性、情绪？
2. **检查品牌要求**：如果用户提到了公司/组织，需要考虑其品牌颜色和标识
3. **调色板匹配内容**：选择符合主题的颜色
4. **说明设计方案**：编写代码前解释你的设计选择

**要求**：
- ✅ 编写代码**之前**先声明符合内容的设计方案
- ✅ 仅使用网页安全字体：Arial, Helvetica, Times New Roman, Georgia, Courier New, Verdana, Tahoma, Trebuchet MS, Impact
- ✅ 通过大小、字重、颜色创建清晰的视觉层级
- ✅ 保证可读性：高对比度、合适的文本大小、清晰对齐
- ✅ 保持一致性：在所有幻灯片中重复图案、间距和视觉语言

##### 调色板选择
**创意选色原则**：
- **不要用默认色**：选择真正匹配当前主题的颜色，不要自动套用默认选项
- **多角度考虑**：主题、行业、情绪、能量水平、目标受众、品牌标识（如有提及）
- **大胆尝试**：可以尝试非常规组合——医疗演示不一定是绿色，金融不一定是藏青色
- **构建调色板**：选择3-5个搭配和谐的颜色（主色+辅助色+强调色）
- **保证对比度**：文本必须在背景上清晰可读
