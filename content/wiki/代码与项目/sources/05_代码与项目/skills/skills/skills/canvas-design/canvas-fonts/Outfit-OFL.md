# Outfit 字体 SIL Open Font License v1.1 声明

> [!NOTE] 来源路径
> `raw/05_代码与项目/skills/skills/skills/canvas-design/canvas-fonts/Outfit-OFL.txt`

## TL;DR
Outfit 字体基于 SIL 开放字体许可证 1.1 版发布，可以自由免费使用、研究、修改和重新分发，限制仅为：字体本身不能单独售卖、修改版不能使用原保留字体名称（需原作者书面授权除外）、修改后的字体也必须沿用本许可证，你用这个字体创作的作品不受本许可证约束。

## 核心要点
1. **权利范围**：任何人都可以免费使用、复制、修改、合并、嵌入、重新分发本字体软件，也可以售卖修改或未修改版本的字体
2. **核心限制**：
   - 字体软件本身（无论原版还是修改版）不得单独售卖
   - 任何分发版本都必须附带本版权声明和许可证文本
   - 未获得原版权持有人书面授权的情况下，修改版不得使用原保留字体名称（仅对面向用户的主字体名称生效）
   - 不得使用原版权持有人、原作者的名称为修改版做推广宣传（除非获得书面授权）
   - 无论修改与否，字体软件本身必须始终使用本许可证分发，不得更换其他许可证
3. **范围例外**：使用本字体创作的文档/作品本身不受本许可证的约束
4. **免责声明**：字体软件按「原样」提供，不提供任何明示或暗示的保证，版权方不对使用本字体产生的任何损失负责
