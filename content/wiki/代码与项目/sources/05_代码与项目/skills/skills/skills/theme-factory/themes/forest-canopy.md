# Forest Canopy 主题

> [!TIP] TL;DR
> Forest Canopy 是一款以茂密森林为灵感的自然风格设计主题，采用大地色系配色，适合环境相关、户外品牌、有机产品类内容使用。

## 要点
1. **设计定位**：自然沉稳风格，灵感源于茂密森林环境，采用大地配色体系
2. **配色方案**：
   | 色号 | 用途 |
   |------|------|
   | `#2d4a2b` (Forest Green) | 主深绿色 |
   | `#7d8471` (Sage) | 柔化绿色强调色 |
   | `#a4ac86` (Olive) | 浅强调色 |
   | `#faf9f6` (Ivory) | 背景、文本底色 |
3. **排版方案**：
   - 标题：FreeSerif Bold
   - 正文：FreeSans
4. **适用场景**：环保主题演示、可持续发展报告、户外品牌、健康内容、有机产品
