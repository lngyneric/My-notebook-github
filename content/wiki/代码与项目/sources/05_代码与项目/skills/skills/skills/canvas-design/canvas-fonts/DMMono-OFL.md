## TL;DR
DM Mono 字体基于 **SIL 开放字体许可证 1.1 版** 发布，你可以免费使用、研究、修改、重新分发这个字体，也可以随你的软件捆绑销售这个字体，唯一的核心限制：
1. 不能单独出售字体软件本身
2. 修改版不能使用原字体的保留名称，除非获得版权方书面授权
3. 无论修改与否，字体本身必须始终以本许可证分发，不能更换其他许可证
4. 用这个字体创作的文档本身不受本许可证约束

## 许可证核心要点
### 许可证目标
促进全球协作字体项目开发，支持学术和语言社区的字体创作，提供免费开源的字体共享与合作改进框架。

### 关键定义
| 术语 | 定义 |
|------|------|
| 字体软件（Font Software） | 版权方根据本许可证发布、明确标注的文件集合，可包含源文件、构建脚本和文档 |
| 保留字体名称（Reserved Font Name） | 版权声明后明确指定为保留名称的字体名 |
| 原始版本（Original Version） | 版权方分发的字体软件组件的原始集合 |
| 修改版本（Modified Version） | 对原始版本添加、删除、替换部分或全部组件，更改格式或移植到新环境生成的衍生版本 |
| 作者（Author） | 任何为字体软件做出贡献的设计师、工程师、程序员、技术作者或其他人员 |

### 许可条件
1. ❌ 字体软件本身（无论原始/修改版）不得单独出售
2. ✅ 原始/修改版字体可以和任意软件捆绑、重新分发或一起出售，条件是每份分发都必须包含本版权声明和本许可证
3. ❌ 除非获得版权方明确书面许可，修改版不得使用保留字体名称（该限制仅对面向用户展示的主字体名生效）
4. ❌ 不得使用版权方或原作者名称推广修改版，除非是为了标注原贡献或获得对方书面许可
5. ✅ 无论修改与否，字体软件必须始终以本许可证分发，不得更换其他许可证；**使用该字体创作的文档本身不受本规则约束**

### 终止与免责
- 如果违反上述任何条件，本许可证自动失效
- 字体软件按「原样」提供，不提供任何明示或暗示的保证（包括适销性、特定用途适用性、不侵权的保证），版权方不对字体软件的使用或无法使用产生的任何索赔、损害或其他责任负责
