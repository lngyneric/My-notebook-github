# ArsenalSC 字体许可证信息
来源路径：`raw/05_代码与项目/skills/skills/skills/canvas-design/canvas-fonts/ArsenalSC-OFL.txt`

## TL;DR
ArsenalSC 字体采用 **SIL Open Font License 1.1 授权，可免费使用、研究、修改和分发，禁止单独售卖字体本身，修改版不能使用保留字体名（除非获得版权方书面授权，修改后的字体也必须继续使用本授权，可和其他软件捆绑分发/售卖，不限制用该字体创作的文档。

## 要点
- 版权所有：2012 The Arsenal Project Authors (andrij.design@gmail.com)
- 授权类型：SIL 开放字体许可证 1.1 版本
- 允许的行为：
  1. 可免费使用、研究、复制、合并、嵌入、修改字体软件，可分发、销售修改/未修改版本的字体
  2. 可将字体（含衍生版本）和任意软件捆绑、重新分发、随软件售卖
  3. 使用本字体创作的文档不受本许可证约束，无需遵守字体本身的授权要求
- 限制条件：
  1. 字体软件本身（原始/修改版本，都不能单独售卖
  2. 任何分发版本都必须保留本版权声明和许可证文本
  3. 修改版本不能使用保留字体名，除非获得版权方书面许可，该限制仅针对面向用户的主字体名
  4. 不得使用版权方/作者姓名宣传修改版本，除非获得授权或仅作贡献标注
  5. 修改后的字体软件必须仍然使用本授权分发，不能更换为其他许可证
- 免责：字体软件按“现状”提供，不提供任何明示或暗示的担保，版权方不对使用产生的损害负责
