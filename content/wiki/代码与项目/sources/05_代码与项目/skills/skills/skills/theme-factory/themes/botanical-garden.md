# Botanical Garden 主题

> [!TIP] TL;DR
> Botanical Garden 是一个清新自然风格的演示主题，以植物园为灵感设计配色，适合与自然、餐饮、农业相关的演示场景。

---

## 要点
- 风格定位：清新有机，以植物园为灵感的充满活力的演示主题
- 核心配色（共4种）：
  | 颜色名称 | 色值 | 说明 |
  | -------- | ---- | ---- |
  | Fern Green（蕨绿） | `#4a7c59` | 浓郁自然绿色 |
  | Marigold（金盏花色） | `#f9a620` | 明亮花卉强调色 |
  | Terracotta（赤陶色） | `#b7472a` | 大地暖色调 |
  | Cream（奶油色） | `#f5f3ed` | 柔和中性背景色 |
- 排版规范：
  - 标题：DejaVu Serif Bold
  - 正文：DejaVu Sans
- 适用场景：园艺中心、食品演示、农场直供内容、植物品牌、天然产品
