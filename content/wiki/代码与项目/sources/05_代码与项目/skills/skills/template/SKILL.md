# template-skill

## TL;DR
这是一个技能模板文件，用于为Claude定义新技能，需要替换占位内容后填写具体的技能说明与使用规则。

## 要点
- 技能标识名称为 `template-skill`
- 技能描述部分需要替换为实际技能的说明，以及Claude使用该技能的场景
- 具体的使用说明需要填写在标题下方的占位区域

## 引用证据片段
```markdown
---
name: template-skill
description: Replace with description of the skill and when Claude should use it.
---

# Insert instructions below
```

> [!WARNING] 冲突：本文件为模板占位文件，所有描述文本均为待替换内容，无实际有效技能定义，与正式技能内容存在必然冲突。
