# Anthropic 风格的PPT生成

> [!INFO]
> 来源路径：`raw/05_代码与项目/guizang-s-prompt-main/guizang-s-prompt-main/image/Anthropic 风格的PPT生成.md`

---

## TL;DR
本提示词用于让 Nano Banana Pro 依据指定文章生成符合Anthropic温暖学术人文主义风格的中文PPT，要求先出大纲再逐页生成，适配中学生理解难度，输出时一页一张图。

---

## 要点
- 适配模型：Nano Banana Pro
- PPT目标受众：中学生，要求内容可被中学生理解
- 生成流程：先输出PPT大纲、规划每页内容，再逐页生成对应PPT页面，保证整体风格一致
- 设计风格：Anthropic/Claude 「温暖学术人文主义」
- 具体设计规范：
  - 背景：暖米色/奶油色 `#F3F0E9`，模仿高级纸张质感
  - 字体：标题使用优雅衬线体，正文使用现代无衬线体
  - 配色：主色调为赤陶红 `#D67052`、芥末黄 `#F0B857`，点缀深海军蓝，禁止使用霓虹色、纯黑色
  - 视觉元素：排版使用网格布局，插图为抽象有机黑色手绘线条画（置于赤陶红纯色色块之上），关键信息使用卡片布局
  - 图表：扁平化极简柱状图，强调数据对比，去除多余边框
- 输出要求：文字图像均由 Nano Banana Pro 生成，禁止将所有PPT合为一张图，要求一页一张图

## 原始提示词原文
```
帮我根据下面这个文章做一套中学生都能理解的中文PPT。

先写1个PPT大纲，规划出每一页的PPT的内容。

然后将每一页的PPT内容分别扔给Nana Banana pro生成对应页面的PPT，需要确保风格一致。

PPT的具体风格应该为请“Anthropic/Claude 风格”的“温暖学术人文主义”设计。

背景：使用暖米色/奶油色 (# F3F0E9) 作为底色，模仿高级纸张质感。

字体：标题使用优雅的衬线体（Serif），正文使用现代无衬线体（Sans-serif）。

配色：主色调为赤陶红 (# D67052) 和芥末黄 (# F0B857)，搭配深海军蓝作为点缀。避免使用霓虹色或纯黑色。

视觉元素：使用注重排版的网格布局，插图风格应为抽象的、有机的黑色手绘线条画，置于赤陶红纯色色块之上，部分关键信息使用卡片布局。

图表：扁平化、极简的柱状图，强调数据对比，去除多余边框。

文字和图像都由 Nano Banana Pro 生成，另外不要将PPT 变成一整张图，一页一张图。

文章内容为：
```

> [!WARNING] 冲突标注
