# 天气移轴 Q 版模型

> [!tldr 这是一个基于AI绘图提示词方案，用于生成带天气信息的地点轴侧微缩Q版景观海报/自媒体封面，适配Nano Banana Pro、Seedream模型，生成效果软润可爱，支持经纬度/地点两种输入方式。

## 概述
从宝玉玩法获取灵感，优化了模型视觉效果，天气以拟物化方式呈现，支持输入经纬度或地点描述，文字排版更精细，整体风格软润可爱。

## 适配模型
- Nano Banana Pro
- Seedream

## 提示词（用于生成海报/自媒体封面
> 海报设计、自媒体封面设计：查找经纬度位于 52.891970728167614, 122.4549778092535 的地点并且获取地点的天气和时间。
>
> 画面的主体是当地代表性的建筑或者景观轴侧微缩模型，上方是当前天气的微缩模型，比如云、太阳等。梦工厂风格，3D建模，细腻、柔和的光线投影，画面周围大面积留白，画面底部居中无衬线体小字写上位置信息和天气图标和时间以及中文位置介绍文案。高品质画面输出。

## 引用证据片段
> 从宝玉玩法来的灵感，优化了一下整个模型的视觉效果，现在更加软润可爱。
>
> 天气会以更加更加拟物化方式呈现，你可以输入经纬度也可以写地点，文字排版也更加的精细。
