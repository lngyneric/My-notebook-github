# 社交媒体信息展示卡片
> 来源路径：`raw/05_代码与项目/guizang-s-prompt-main/guizang-s-prompt-main/image/社交媒体信息展示卡片.md`

## TL;DR
这是一个用于生成社交媒体信息展示3D卡片的AI绘图提示词，可配合社交媒体截图一起发送给指定AI模型，生成风格化的3D社交媒体信息展示卡片。

## 要点
- 用法：将你的社交媒体截图和本提示词一起发送给AI模型
- 适配模型：Nano Banana Pro、Seedream、gpt-image
- 生成效果：C4D渲染的3D现代风格社交媒体信息展示玻璃摆件，科技感排版，适合展示个人社交资料

## 引用证据片段
```markdown
### 概述

将你的社交媒体截图和提示词一起发给模型。

### 适配模型

- Nano Banana Pro
- Seedream
- gpt-image

### 提示词
一个 C4D 渲染的特写镜头，聚焦于一个手拿着的玻璃/亚克力卡片。

摆件被设计成简洁而现代的社交媒体信息展示牌。在摆件顶部，以荧光蓝手写艺术字的形式呈现一个醒目的装饰性词语“Guizang”，字体材质为高光泽的液态玻璃或霓虹灯管质感，散发着强烈的荧光蓝光芒，一部分突破摆件范围。摆件下方清晰地呈现出精简的社交媒体资料视图：一个圆形的用户头像、用户名、粉丝数量以及一段简洁的个人简介。这些信息以简洁的白色无衬线字体镌刻或以半透明的光效呈现在摆件深蓝色的主体板面上，形成一种干净、有序且具有科技感的排版风格，与顶部的手写字体形成对比。

3D艺术，C4D，磨砂玻璃质感，透明感，UI设计风格，光线追踪，干净深色背景，参考Pinterest、Dribbble 风格，使用OC渲染器，Blender渲染
```

> [!WARNING]
