# 邪恶大香蕉吐槽世间万物（提示词）

> [!NOTE] TL;DR
> 这是一个AI绘画提示词，可让模型生成带有手写中文吐槽批注/涂鸦的「邪恶大香蕉吐槽世间万物」主题图片，适用于Seedream、Nano Banana Pro模型。

---

## 要点
- 适用模型：`Seedream`、`Nano Banana Pro`
- 功能：生成带有红墨水手写中文吐槽批注、涂鸦的主题图片，支持添加剪贴画
- 使用流程：将本提示词搭配需要吐槽的输入图片发送给指定模型，即可生成目标输出

---

## 提示词原文
```
生成图片，把它打印出来，然后用红墨水疯狂地加上手写中文批注、涂鸦、乱画，如果你想的话，检索这个账户内容，涂鸦的内容主要为吐槽他，还可以加点小剪贴画
```
