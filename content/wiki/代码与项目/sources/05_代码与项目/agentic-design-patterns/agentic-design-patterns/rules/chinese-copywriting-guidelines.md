# 中文文案排版指北
## 摘要
本文档是一份中文文案排版的规范指南，目的是统一中文文案的排版用法，降低团队沟通成本，提升内容呈现的美观性与专业气质，涵盖空格、标点符号、全角半角、名词书写等多方面的排版规则，并对部分存在争议的用法做了说明。

## 核心排版规则
### 空格规则
| 场景 | 规范要求 | 例外情况 |
| ---- | ---- | ---- |
| 中文与英文之间 | 需要增加空格 | 「豆瓣 FM」等官方已定义格式的产品名词除外 |
| 中文与数字之间 | 需要增加空格 | 无 |
| 数字与单位之间 | 需要增加空格 | 度数、百分比与数字之间不需要加空格 |
| 全角标点与其他字符之间 | 不需要增加空格 | 无 |

目前`text-spacing`等自动添加空格的CSS特性尚未普及，仍需要保持手动添加空格的习惯。

### 标点符号规则
禁止重复使用标点符号，重复标点会破坏内容美观性，仅允许在表达强烈情绪时的「？！」组合用法。

### 全角与半角规则
1. 中文标点需使用全角格式；中文句子内夹入英文书籍、报刊名称时，不使用中文书名号，应以英文斜体标注
2. 数字默认使用半角字符，仅设计稿、宣传海报等需要对齐的特殊场景可使用全角数字
3. 完整的英文整句、特殊名词内部，需使用半角标点

### 名词书写规则
1. 专有名词需要遵循官方正确的大小写格式，即使需要配合视觉调整大小写，也应在HTML中保留标准大小写，通过CSS修改表现形式
2. 不使用不地道的不规范缩写

## 争议用法
以下用法从语法角度均正确，是否遵循由使用者自行选择：
1. 链接之间增加空格：推荐在文字与链接、链接与后续文字之间增加空格提升可读性
2. 简体中文使用直角引号：推荐使用「」『』的直角引号格式，而非弯引号“”‘’
