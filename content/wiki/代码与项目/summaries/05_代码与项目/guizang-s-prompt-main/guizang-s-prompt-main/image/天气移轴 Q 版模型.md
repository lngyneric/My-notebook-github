# 天气移轴 Q 版模型
## 概述
本模型灵感源自宝玉玩法，对整体视觉效果进行了优化，呈现风格更软润可爱。
天气内容以高度拟物化的方式呈现，支持输入经纬度或具体地点进行查询生成，文字排版也更为精细。

## 适配模型
- Nano Banana Pro
- Seedream

## 提示词（适用场景：海报设计、自媒体封面设计）
查找经纬度位于 52.891970728167614, 122.4549778092535 的地点并且获取地点的天气和时间。
画面的主体是当地代表性的建筑或者景观轴侧微缩模型，上方是当前天气的微缩模型（如云、太阳等）；采用梦工厂风格3D建模，搭配细腻、柔和的光线投影，画面周围设置大面积留白；画面底部居中以无衬线体小字标注位置信息、天气图标、时间以及中文位置介绍文案，输出高品质画面。
