# 3D信息图提示词
## 概述
本提示词体系适用于含实物的非抽象内容展示场景，生成内容包含精美3D渲染实物模型；因生成图包含较多文字内容，建议在AI Studio或其他可生成高清图片的产品中使用。
## 适配模型
- Nano Banana Pro
## 提示词规则
### 核心生成要求
基于输入的文字主题，创作高密度的中文3D信息图。
### 结构与风格要求
1. **顶部：主标题区**
居中展示对应主题的3D艺术字标题。
2. **中间内容区**
展示主题相关物品或抽象内容的3D微缩模型，要求造型极其复杂华丽、采用高级材质（如发光、透明、镀金）、体积庞大、带有炫酷特效光晕。
3. **信息叠加层（Smart UI）**
配置悬浮标签：在每个模型上方，悬浮一个3D气泡，标注该模型或对应内容的名称。
4. **底部：数据矩阵区**
- 生成整齐的多列数据表，承载输入的文本信息；
- 自动生成参数：根据主题自动筛选多个最关键参数，以图形化进度条或数字形式展示。
### 渲染规范
- 视角：采用正面平视或30度等轴测视角，确保核心展示物品处于同一水平线；
- 材质：结合「盲盒玩具」与「产品渲染」风格，兼具可爱感与高物理真实感（参考C4D / Octane Render效果）；
- 背景：采用干净的纯色摄影棚背景，搭配柔和投影。
