# 任意领域从夯到拉打分提示词
## 摘要
本工具为适配特定AI模型的提示词体系，可驱动AI完成任意指定领域的全网调研，基于产品/作品的热度、口碑、用户反馈等数据，按照「夯-顶级-人上人-NPC-拉完了」五级分层标准，生成采用Bento Grid布局的可视化评价信息图。
## 适用模型
- Seedream
- Nano Banana Pro
## 使用方式
将提示词中「用户指定目标领域/产品」模块下的方括号占位符替换为需调研打分的具体领域（如2024年热门智能手机、无糖茶饮料品牌、近十年漫威电影、程序员常用代码编辑器等），发送给适配模型即可自动生成对应评价信息图。
## 核心提示词架构
### 核心任务指令
要求AI兼具实时网络搜索能力与顶尖数据可视化设计能力，分两个阶段执行任务：
1. **调研阶段**：针对用户指定的领域开展全网调研，搜集领域内不同子产品、型号或作品的大众口碑、市场热度、专业评测及用户反馈数据
2. **可视化阶段**：基于调研结果，按照定义的五级分层标准设计专业模块化信息图
### 目标领域占位符
```
[在此处填写你需要调研的内容，例如：2024年热门智能手机、市面上的无糖茶饮料品牌、近十年的漫威电影、程序员常用的代码编辑器]
```
### 图像设计规范
#### 整体风格
采用「Bento Grid（便当盒网格）」布局的现代模块化信息图，背景干净简洁，聚焦内容呈现，视觉上需体现从高到低的强烈层级落差感。
#### 五级分层标准（严格执行）
| 等级层级 | 等级名称 | 调研填充标准 | 视觉表现要求 |
|----------|----------|--------------|--------------|
| 第1级（最高） | 夯 (Hāng) | 领域内公认的「版本之子」，具备统治级热度、无可争议的顶流产品/作品 | 占据画面最上方或最大版面模块，采用爆裂红与辉煌金配色，带有光晕或能量外溢特效；字体最大最粗，模块内展示代表性产品名称/高质量图像，搭配极简赞美短语（如「全网吹爆」「神作」） |
| 第2级 | 顶级 | 硬核实力派项目，热度或略逊于「夯」级，但口碑极佳，为行家首选的优质内容 | 位于画面第二层，采用燃烧橙与金属银配色，设计扎实富有质感，展示代表性实力派产品 |
| 第3级 | 人上人 | 优越之选，品鉴力在线、无踩坑风险的中坚力量产品，代表一定的鉴赏水平 | 位于画面中层，采用柠檬黄与冷灰配色，风格现代清爽，展示代表性优质中产向产品 |
| 第4级 | NPC | 无记忆点的大众脸流水线产物，无功无过、易被遗忘，需标注具体产品/品牌/主体，不得含糊 | 位于画面中下层，采用面包色/米色/纸板棕配色，设计普通重复、缺乏个性，展示平庸类产品 |
| 第5级（最低） | 拉完了 | 公认「避雷针」「智商税」、灾难级失败产品，甚至属于不如没有的存在，需标注具体产品/品牌/主体，不得含糊 | 挤在画面最底部或角落，视觉空间被压缩；采用绝望黑、惨白色调，带有明显数字故障（Glitch）、破碎或腐烂特效；展示著名「翻车」产品，搭配警示性短语（如「快逃」「大冤种」） |
