# 邪恶大香蕉吐槽世间万物
## 摘要
本页面记录了一套用于指定AI图像生成模型的提示词方案，可引导模型生成带有手写中文吐槽批注、涂鸦的「邪恶大香蕉吐槽世间万物」主题图像。
## 关键信息
### 适用模型
- Seedream
- Nano Banana Pro
### 使用方式
将对应提示词与需要吐槽的图片一同发送给支持的模型，模型将输出符合要求的主题图片。
### 提示词原文
生成图片，把它打印出来，然后用红墨水疯狂地加上手写中文批注、涂鸦、乱画，如果你想的话，检索这个账户内容，涂鸦的内容主要为吐槽他，还可以加点小剪贴画
