# 诺基亚手机照片滤镜
## 摘要
本方案为适配特定AI图像生成模型的复古风格照片滤镜提示词，可将用户输入的照片转换为模拟早期诺基亚彩屏手机相机预览界面效果的图像，自带千禧年Y2K美学与低保真科技质感。
## 适用模型
- Seedream
- Nano Banana Pro
## 使用方式
将本提示词与需要添加滤镜的照片一同发送给适配模型，模型将自动生成带有诺基亚手机照片滤镜的目标图像。
## 提示词详情
### 核心指令
基于附带的照片，将图像显示在复古手机的屏幕界面内，并进行特定的风格变换。
### 整体画面描述
为抓拍的、略微倾斜的复古诺基亚经典直板机型（如6610或同期早期彩屏机型）特写，手机呈对角线放置在画面中；低分辨率发光LCD屏幕占据构图主体，坚固塑料外壳、物理T9键盘与导航键顶部仅部分可见，边缘被裁剪。
### 屏幕内容规则
#### 照片内容变换
输入照片中的人物服装将替换为千禧年Y2K流行时装（如闪亮金属面料、天鹅绒运动装、水钻细节、层叠网眼织物）；整体呈现早期拍照手机美学：明显像素网格（纱窗效应）、有限且略微褪色的调色板、块状压缩伪影。
#### 复古UI叠加
画面覆盖低像素单色诺基亚系统UI元素：
- 屏幕顶部：左侧为像素化信号强度条、中间为「Camera」文字、右侧为块状电池图标
- 屏幕底部角落：块状像素字体软键标签，左侧为「Options」（选项）、右侧为「Back」（返回）
### 氛围与光影要求
屏幕呈现LCD特有的绿蓝色背光色调，微弱光线投射在周边塑料边框上；整体氛围怀旧、具有互动感，呈现真实的低保真（Lo-fi）科技感。
### 参数配置
| 配置项 | 具体参数 |
| ---- | ---- |
| 画面比例 | 4:5 竖幅 |
| 相机视角 | 复古手机屏幕微距特写，手持视角 |
| 屏幕模拟 | 早期CSTN或TFT LCD屏幕，可见像素颗粒，特有的绿色色偏 |
| UI元素规范 | 复古低分辨率单色像素图标、块状文字覆盖 |
| 内容变换规则 | 将人物服装替换为Y2K千禧年流行风格 |
| 调色风格 | 低饱和度冷色调，数字噪点，颜色抖动伪影，屏幕荧光 |
