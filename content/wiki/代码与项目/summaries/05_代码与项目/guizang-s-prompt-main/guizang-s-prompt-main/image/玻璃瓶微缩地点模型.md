# 玻璃瓶微缩地点模型
## 摘要
本页面记录了一款面向AI绘画的创意主题提示词框架，可生成将指定地点标志性景观制作为Q版微缩模型并封存于玻璃罐内的视觉作品，适用于海报设计、自媒体封面设计场景，能够具象化用户独有的旅行体验。
## 概述
该创意主题的核心逻辑是将个人独一无二的旅行体验具象化，把地标景观“装进瓶子”；画面底部默认的地点相关文字介绍可自定义替换为个人感想。
## 适配AI绘画模型
- Nano Banana Pro
- Seedream
## 核心提示词规范
### 前置信息准备
生成前需先获取目标地点（可输入地点名称或经纬度坐标）的标志性景观/建筑，以及该地点特定时间的天气状况。
### 画面主体设定
画面核心主体为精致透亮、带有厚度感的玻璃容器（形态参考圆顶玻璃罩、标本罐或复古水晶球），平稳放置于干净柔和的平面上；容器内部封存该地点代表性景观的Q版微缩模型，模型材质呈现软陶或磨砂树脂类的高级软润感，色彩治愈；容器内景观上方悬浮对应天气的微缩模型（如Q版棉花糖状云朵、发光小太阳、晶莹雨滴等）。
### 风格与视觉效果要求
1. 整体风格：采用梦工厂动画风格的3D建模效果，整体光线柔和梦幻
2. 材质表现：重点强化玻璃材质的真实感，清晰呈现光线透过玻璃产生的折射、反光、焦散效果，突出内部景物的珍贵感
3. 镜头效果：采用强烈的移轴摄影镜头效果，焦点清晰集中于玻璃罐内的微缩景观，罐子外部及背景完全虚化模糊
### 画面排版与标注规范
画面保留大面积留白以维持干净高级的视觉质感；画面底部居中位置使用无衬线体小字清晰标注以下内容：
- 位置信息：地点名称及具体经纬度
- 天气信息：天气图标、对应温度与时间
- 自定义文案：一段关于该旅行地点的精简中文介绍，侧重描述相关记忆或氛围
### 输出要求
生成高品质画面，细节丰富。
