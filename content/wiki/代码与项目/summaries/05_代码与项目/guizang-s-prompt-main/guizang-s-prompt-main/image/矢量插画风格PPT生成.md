## 核心设计规范
### 视觉与插画规范
1. **基础插画风格**：采用扁平化矢量插画（Flat Vector Illustration），所有元素必须带有清晰、统一粗细的黑色封闭轮廓线（Monoline/Stroke）；填色简洁，仅可使用少量阴影，严禁使用渐变色或3D渲染效果。
2. **构图规则**：插画采用横向全景式构图（Panoramic），固定占据版面顶部1/3的空间。
3. **线条规范**：使用统一粗细的黑色单线描边，所有物体（建筑、植物、云朵等）均需带有封闭黑色轮廓，风格类似填色书线稿；线条末端做圆润处理，避免尖锐棱角。
4. **几何化处理要求**：将复杂物体简化为基础几何形状，例如树木简化为棒棒糖形/三角形、建筑简化为矩形块面、窗户简化为整齐方格网格，整体呈现「玩具模型」般的可爱感，无需追求写实细节。
5. **空间与透视规则**：采用平视或略微俯视的2.5D视角（自由度高于标准等轴测视角），通过图层前后遮挡表现纵深；禁用大气透视效果，所有图层清晰度保持一致。
6. **装饰元素要求**：可在画面空白处添加放射状线条（代表阳光/能量）、药丸形云朵、小圆点、星星等装饰性几何元素，平衡画面视觉密度。

### 配色规范
整体采用复古柔和色调：
- 背景：米色/奶油色（Cream/Off-white）纸张纹理感底色
- 强调色：珊瑚红、薄荷绿、芥末黄、赭石色（Burnt Orange）、岩石蓝

### 字体排版规范
- 主标题：使用巨大、加粗的复古衬线体（Retro Serif），兼顾权威感与优雅感
- 副标题：使用放置于矩形色块内的全大写无衬线体
- 正文：使用清晰易读的几何感无衬线体
