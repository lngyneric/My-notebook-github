# Anthropic 风格的PPT生成
## 摘要
本页面记录了一套面向Nano Banana Pro模型的PPT生成提示词方案，目标是将指定文章转化为中学生可理解的中文PPT，明确了Anthropic/Claude风格「温暖学术人文主义」设计的具体规范与生成流程。

## 关键要点
1. **适配模型**：指定使用Nano Banana Pro完成PPT的文字、图像全内容生成
2. **生成流程**：
   - 第一步：基于目标文章产出完整PPT大纲，明确单页内容规划
   - 第二步：拆分单页内容提交模型生成，要求每页为独立图片，禁止生成单张整图形式的PPT
3. **核心设计规范（温暖学术人文主义风格）**：
   - 背景：采用暖米色/奶油色（# F3F0E9），模仿高级纸张质感
   - 字体：标题使用优雅衬线体（Serif），正文使用现代无衬线体（Sans-serif）
   - 配色：主色调为赤陶红（# D67052）、芥末黄（# F0B857），以深海军蓝为点缀，禁用霓虹色、纯黑色
   - 视觉元素：采用注重排版的网格布局，搭配置于赤陶红色块上的抽象有机黑色手绘线条画，关键信息使用卡片布局
   - 图表：采用扁平化极简柱状图，强调数据对比，去除多余边框

## 原始提示词片段
```
帮我根据下面这个文章做一套中学生都能理解的中文PPT。
先写1个PPT大纲，规划出每一页的PPT的内容。
然后将每一页的PPT内容分别扔给Nana Banana pro生成对应页面的PPT，需要确保风格一致。
PPT的具体风格应该为请“Anthropic/Claude 风格”的“温暖学术人文主义”设计。
```
