# 云端岛屿城市海报
## 摘要
本页面收录了专为AI图像生成设计的「云端岛屿城市」主题数字艺术海报提示词规范，包含适用模型、画面元素规则、风格标准等完整内容，可直接用于对应模型的图像生成任务。

## 适用模型
- Seedream
- Nano Banana Pro

## 核心提示词规范
### 基础定位
针对指定[城市名称]生成城市渲染类数字艺术海报。

### 核心主体要求
画面核心为占据大部分画幅、漂浮于白云上方的微型岛屿，岛屿外形与目标城市的地图轮廓一致；岛屿内部无缝融合城市独有的标志性地标、自然景观、文化元素与特有鸟类，建筑不宜过于密集；采用航拍视角，搭配电影级光影、鲜艳色彩与阳光反射效果。

### 时空融合要求
岛屿需实现目标城市历史与现代的无缝衔接：一部分呈现城市最具代表性的古代历史建筑，另一部分平滑过渡为城市现代地标建筑与天际线景观。

### 背景元素要求
微型岛屿漂浮于浩瀚云海之上，云海的表现形式需采用目标城市所属文化圈的传统艺术风格。

### 文字装置要求
目标城市的立体拼音或英文名3D文字漂浮于微型岛屿上方，定位为展现生态与文化共生的微缩生态装置。

### 信息排版层要求
在画面四周与主体周围叠加极简高雅、具备博物馆展板质感的信息排版层，整体排版留白充足、克制干净、平衡感强，呈现艺术品观赏质感：
1. 核心城市信息使用经典衬线字体，辅助数据使用极细极简无衬线体；
2. 画面角落参照古典地图集或高端杂志扉页的排版方式，用衬线体标注城市地理坐标、别称/建城年份、实时天气等装饰性背景信息。

## 风格规范
需符合以下生成风格要求：
Octane Render、C4D、等距城市（Isometric City）、微观世界（Micro World）、生机生态系统（Living Ecosystem）、8K分辨率、梦工厂（DreamWorks）风格、3D建模、精致质感、柔和光线投射。
