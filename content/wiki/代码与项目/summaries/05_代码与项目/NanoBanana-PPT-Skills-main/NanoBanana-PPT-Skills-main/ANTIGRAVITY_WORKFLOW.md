# PPT Generator Workflow 提示词模板
## 摘要
这是为内置 Nano Banana Pro 的 AI 编程软件（如 Antigravity）设计的 Global Workflow 模板，用户仅需填写指定字段即可实现基于文档内容的专业PPT自动生成功能，支持2种视觉风格，适配商务演示、教育培训等多场景使用。

## 核心特性
- 智能文档分析与页面结构自动规划
- 固定输出16:9标准PPT比例，支持2K/4K分辨率
- 内置2种专业视觉风格：渐变毛玻璃卡片风格、矢量插画风格
- 全流程自动化：需求采集→内容规划→提示词生成→图片生成→结果汇总
- 支持单页迭代调整、生成失败重试等灵活操作

## 字段填写说明
### Description 字段（0-250字符）
> 基于文档内容自动生成专业PPT图片。支持2种风格（渐变毛玻璃/矢量插画），16:9比例，2K/4K分辨率。智能分析文档，规划页面结构，调用Nano Banana Pro生成高质量演示文稿。适用于商务演示、教育培训、创意提案等场景。
> 字符数：132/250 ✅

### Content 字段（0-12000字符）
Content为完整的Workflow执行逻辑，包含以下核心模块：
#### 1. 核心能力定义
明确PPT生成助手的5项核心能力：智能文档分析与内容规划、调用Nano Banana Pro生成16:9高清图片、支持多种专业视觉风格、自动规划页面类型、生成2K/4K分辨率图片。

#### 2. 6步标准工作流程
##### 步骤1：接收用户输入
向用户采集4项核心配置信息：
- 文档内容：支持文本、Markdown格式输入或本地文件路径
- 页数范围：提供5页（5分钟快速演示）/5-10页（15分钟标准演示）/10-15页（30分钟深入讲解）/20-25页（60分钟完整培训）/自定义页数5种选项
- 视觉风格：提供渐变毛玻璃卡片风格、矢量插画风格2种选项，附适用场景提示
- 分辨率：提供2K（推荐日常使用）、4K（适合打印/大屏展示）2种选项

##### 步骤2：文档分析与内容规划
基于输入的文档内容与页数，按预设结构规则规划PPT页面，为每页分配「封面/内容/数据」类型，向用户展示完整的页面规划并确认是否调整。
> 预设页数对应结构规则：
> - 5页结构：封面 + 3页核心内容 + 总结/行动建议
> - 5-10页结构：封面 + 目录/引言 + 6页详细内容 + 总结+下一步
> - 10-15页结构：封面 + 引言/背景 + 9页核心内容 + 案例/数据 + 总结
> - 20-25页结构：封面 + 目录 + 引言 + 15页详细内容 + 案例研究 + 关键发现 + 总结

##### 步骤3：生成图像提示词
根据用户选择的视觉风格，为不同页面类型（封面/内容/数据）生成对应专业图像生成提示词，内置两种风格的完整提示词模板：
- 渐变毛玻璃卡片风格：融合Apple Keynote极简主义、现代SaaS产品设计、玻璃拟态风格，搭配极光渐变色、Bento网格布局、高端抽象3D元素
- 矢量插画风格：扁平化矢量设计，统一黑色轮廓线，复古柔和配色，几何化简化元素

##### 步骤4：调用Nano Banana Pro生成图片
按规划逐页生成图片，实时展示生成进度，按`slide-{页码:02d}.png`格式命名文件，内置错误处理机制（单页生成失败则记录错误信息，继续生成后续页面，最后汇总失败页面询问是否重试）。
> 标准调用参数：
> ```
> model: "gemini-3-pro-image-preview"
> aspect_ratio: "16:9"
> image_size: "2K" 或 "4K"（按用户选择）
> ```

##### 步骤5：生成结果汇总
生成完成后向用户展示生成统计、文件列表、使用建议与后续操作选项。

##### 步骤6：提供后续支持
支持4类后续操作：重新生成特定页面、调整指定页面内容、切换风格重新生成、生成HTML预览播放器（可选）。

#### 3. 关键注意事项
- 提示词优化：保持全页面视觉语言统一，单页最多承载3-5个要点，支持多语言内容输入
- 图片质量控制：固定输出16:9标准PPT比例，2K单页文件大小约2-3MB，4K单页约8-10MB
- 用户体验优化：实时反馈生成进度、清晰说明错误原因、支持用户中途调整内容规划

#### 4. 示例对话流程
提供完整的用户交互示例，展示从用户提出PPT生成需求到最终完成输出的全流程交互逻辑。

## 配置步骤总结
1. 打开软件中的 Global Workflows 编辑器（路径：`.gemini > antigravity > global_workflows`），创建新文件 `ppt-generator.md`
2. 复制上述 Description 字段内容，粘贴到软件的 Description 输入框
3. 复制完整的 Content 字段 Markdown 内容，粘贴到软件的 Content 输入框
4. 保存 Workflow 并测试调用，确认功能正常
