# 工作记录 维基领域规范

## 概述
每日报表、工作日志、状态更新

## 目录结构

```
wiki/工作记录/
├── entities/   # 实体（）
├── concepts/   # 概念（工作日报, 状态报告, 会议纪要, 行动计划）
├── summaries/  # raw/ 源文件摘要
├── sources/    # 源文件处理记录
├── SCHEMA.md   # 本领域规范
├── index.md    # 领域索引
└── log.md      # 操作日志

raw/工作记录/  # 不可变源文件
```

## 页面类型
- **entities/** — 人、组织、系统、项目、工具
- **concepts/** — 理论、方法、模型、模式
- **summaries/** — 源文件摘要（LLM 生成）
- **sources/** — 源文件处理记录

## 交叉引用规范
- 使用 `[[页面名]]` 格式
- 跨领域引用: `[[领域/页面名]]`
- 源文件: `source: 文件名`
