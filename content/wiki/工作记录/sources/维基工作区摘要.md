## 三层架构概览
本项目采用三层目录架构划分不同类型内容，结构如下：
```
xcxnotes/
├── input/          ← 输入层: 原始源文件 (只读)
├── wiki/           ← 维基层: LLM 生成和维护的页面
└── output/         ← 输出层: 衍生内容和导出文件
```

> [!NOTE] 引用原始资料
> ```
> xcxnotes/
> ├── input/          ← 输入层: 原始源文件 (只读)
> ├── wiki/           ← 维基层: LLM 生成和维护的页面
> └── output/         ← 输出层: 衍生内容和导出文件
> ```

## 快速开始
### 添加新源文件
1. 将文件放入 `input/raw/`
2. 通知 LLM 处理
3. 检查新创建的页面

### 查询知识
1. 查看 `wiki/index.md` 找到相关页面
2. 或直接提问

## 工具集成
本项目基于以下工具集成搭建工作流：
- **Obsidian**: 主要编辑和浏览工具
- **Obsidian Git**: 版本控制
- **Local REST API**: 程序化访问
- **Dataview**: 动态查询
- **Marp**: 幻灯片生成
