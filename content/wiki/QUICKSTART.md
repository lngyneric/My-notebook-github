# LLM Wiki 工作流程速查

## 核心概念

### 三层架构
1. **输入层 (input/)**: 原始源文件，只读
2. **维基层 (wiki/)**: LLM 生成和维护的页面
3. **输出层 (output/)**: 衍生内容

## 快速操作指南

### 📥 摄入新源文件

**步骤**:
1. 放入源文件: `input/raw/文件名.md`
2. 阅读和理解内容
3. 创建摘要: `wiki/summaries/来源-日期.md`
4. 更新相关页面 (实体、概念等)
5. 更新索引: `wiki/index.md`
6. 记录日志: `wiki/log.md`

**检查清单**:
- [ ] 摘要页面已创建
- [ ] 相关页面已更新
- [ ] 交叉引用已添加
- [ ] 索引已更新
- [ ] 日志已记录

---

### ❓ 查询知识

**步骤**:
1. 查看索引定位相关页面
2. 读取维基页面
3. 综合信息回答
4. 有价值的答案创建新页面
5. 记录查询到日志

**提示**:
- 优先使用内部链接 `[[页面名]]`
- 答案可以是多种格式
- 有价值的探索应该存档

---

### 🔧 维护维基

**定期检查** (每周/每月):
- [ ] 页面间矛盾
- [ ] 过时声明
- [ ] 孤立页面
- [ ] 缺失的页面
- [ ] 缺失的引用
- [ ] 元数据完整性

**维护操作**:
- 更新过时内容
- 创建缺失页面
- 添加缺失引用
- 优化结构

### 📊 常用命令

```bash
# 查看最近 5 条日志
grep "^## \[" wiki/log.md | tail -5

# 统计维基页面数
find wiki -name "*.md" | wc -l

# 查看目录结构
tree wiki/
```

### 📝 页面模板速查

#### 实体页面
```markdown
# [实体名称]

## 基本信息
- 类型: [类型]
- 创建: {{date}}

## 概述
[概述内容]

## 详细内容
[详细内容]

## 相关链接
- [[相关页面]]

## 元数据
```yaml
---
tags: [tag1, tag2]
created: {{date}}
---
```
```

#### 概念页面
```markdown
# [概念名称]

## 定义
[定义]

## 核心理念
[核心思想]

## 应用场景
[场景]

## 相关链接
- [[相关概念]]

## 元数据
```yaml
---
tags: [concept, tag]
created: {{date}}
---
```
```

#### 摘要页面
```markdown
# [源文件标题] 摘要

## 源文件信息
- 原始链接: [URL]
- 作者: [作者]
- 日期: [日期]

## 核心要点
- [要点 1]
- [要点 2]

## 详细内容
[摘要内容]

## 相关维基页面
- [[页面 1]]
- [[页面 2]]

## 元数据
```yaml
---
tags: [summary]
source-url: [URL]
ingested-date: {{date}}
---
```
```

### 🔗 链接约定

- **内部链接**: `[[页面名称]]`
- **外部链接**: `[显示文本](URL)`
- **文件命名**: 小写和连字符，如 `topic-name.md`
- **标签**: 小写，多词用连字符，如 `ai-agents`
