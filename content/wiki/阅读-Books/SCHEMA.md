# 阅读-Books 维基领域规范

## 概述
图书笔记和阅读记录

## 目录结构

```
wiki/阅读-Books/
├── entities/   # 实体（书籍角色, 作者, 系列）
├── concepts/   # 概念（小说分析, 人物关系, 主题思想, 读书笔记）
├── summaries/  # raw/ 源文件摘要
├── sources/    # 源文件处理记录
├── SCHEMA.md   # 本领域规范
├── index.md    # 领域索引
└── log.md      # 操作日志

raw/阅读-Books/  # 不可变源文件
```

## 页面类型
- **entities/** — 人、组织、系统、项目、工具
- **concepts/** — 理论、方法、模型、模式
- **summaries/** — 源文件摘要（LLM 生成）
- **sources/** — 源文件处理记录

## 交叉引用规范
- 使用 `[[页面名]]` 格式
- 跨领域引用: `[[领域/页面名]]`
- 源文件: `source: 文件名`
