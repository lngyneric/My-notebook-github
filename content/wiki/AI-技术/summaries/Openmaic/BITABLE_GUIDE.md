# 飞书多维表格 (Bitable) 接入与自动化指南
## 摘要
本指南用于指导配置飞书多维表格以实现AI课堂的统计与自动化流程，涵盖数据表结构设计、开放平台权限配置、自动化场景搭建及核心凭证获取等内容。

## 1. 飞书多维表格配置
### 1.1 数据表结构设计
需创建名为「AI 课堂学生成绩统计」的多维表格，核心字段定义如下：
| 字段名 | 类型 | 说明 |
| :--- | :--- | :--- |
| 学生姓名 | 文本 | - |
| 飞书 OpenID | 文本 | 用于私聊推送 (通过 OpenClaw 自动填入) |
| 课程名称 | 选项 | - |
| 测验得分 | 数字 | 由 OpenMAIC 回传 |
| 签到状态 | 复选框 | - |
| 学习进度 | 百分比 | - |
| 最后活跃时间 | 日期 | - |

### 1.2 报名表单搭建
在多维表格中添加「表单视图」并发布，学生填写后数据将自动同步至对应数据表。

## 2. 飞书开放平台配置
### 2.1 权限申请
需向飞书开放平台申请以下接口权限：
- `bitable:app`：查看和管理多维表格数据
- `im:message`：发送飞书私聊消息
- `contact:user.employee:readonly`：读取员工基础信息

### 2.2 事件订阅
需订阅 `bitable.app.record.created_v1` 事件，用于 OpenClaw 监听学生新报名记录。

## 3. 自动化场景示例
### 3.1 报名成功自动邀请
- 触发条件：多维表格产生新报名记录
- 执行操作：OpenClaw 调用 OpenMAIC 接口生成课程链接，通过飞书私聊发送给报名学生

### 3.2 成绩达标自动发证
- 触发条件：多维表格「测验得分」字段更新且分值大于80分
- 执行操作：通过飞书原生自动化流向学生推送证书图片

## 4. 核心凭证获取
### App Token 与 Table ID 获取方式
可从飞书多维表格的浏览器地址栏提取，地址格式为：`https://feishu.cn/base/[APP_TOKEN]?table=[TABLE_ID]`，获取后需填入 OpenClaw 的 feishu 插件配置中。
