## 二、完整系统架构
系统采用Karpathy LLM Wiki模式定义的三层分离架构，目录结构如下：
```
xcxnotes/
├── input/          # 输入层 - 原始源文件
│   ├── raw/       # 待整理的现有文件夹内容
│   ├── assets/    # 媒体资源
│   └── README.md
├── wiki/           # 维基层 - LLM 生成和维护
│   ├── entities/  # 实体页面存储目录
│   ├── concepts/  # 概念页面存储目录
│   ├── summaries/ # 摘要页面存储目录
│   ├── index.md   # 核心内容索引
│   ├── log.md     # 操作日志
│   ├── SCHEMA.md  # 完整结构规范
│   ├── QUICKSTART.md # 快速参考指南
│   └── README.md  # 维基使用说明
└── output/         # 输出层 - 衍生内容
    ├── slides/    # 幻灯片输出目录
    ├── reports/   # 报告输出目录
    └── README.md
```

### 各层核心职责
1. **输入层**：存储原始未加工的源文件、媒体资源，是所有知识的上游来源
2. **维基层**：由LLM辅助生成与维护的结构化知识层，包含各类标准化内容页面、规范与索引，是系统的核心载体
3. **输出层**：基于维基内容生成的衍生内容存储层，支持幻灯片、报告、可视化等多种输出格式
