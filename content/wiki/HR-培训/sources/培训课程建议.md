# 企业新任管理者核心培训课程体系
## 摘要
本文整理了面向企业新任管理者的核心培训课程列表，同时明确了当前企业针对管理者培训的四大核心需求，为企业搭建新任管理者培训体系提供课程参考与方向指引。

## 核心重点课程列表
| 课程编号 | 课程名称 | 课程方向 |
|---------|---------|---------|
| LDNM101 | 角色转身：新经理如何攻克转型难题 | 基础管理转型 |
| LDNM102 | 新经理的关键职责和能力 | 管理基础能力 |
| SMSJ101 | 管理者的时间管理法 | 个人效能管理 |
| HRZP101 | 4步GET面试技巧 | 人才选拔技能 |
| LDHT101 | 识别团队角色，因才施用 | 团队管理 |
| OBMS101 | 因人而异的激励 | 员工激励方法 |
| TMEM101 | 高效组织会议 | 会议管理 |
| LDPM101 | 绩效管理与目标设定 | 绩效管理基础 |
| LDPM102 | 绩效跟踪与评估 | 绩效过程管理 |
| LDPM103 | 让棘手的绩效面谈不再难谈 | 绩效沟通 |

## 企业培训核心需求
企业针对新任管理者的培训核心需求分为四类：
1. **管理基础技能**：包含新经理角色转型、时间管理相关能力培养
2. **团队建设能力**：包含人才面试选拔、团队角色识别与适配相关能力培养
3. **绩效管理体系**：包含绩效目标设定、绩效跟踪、绩效面谈全流程能力培养
4. **沟通协作技能**：包含会议管理、跨部门沟通相关能力培养

## 关键要点
- 该课程体系围绕新任管理者从业务岗转管理岗的成长路径搭建，覆盖从个人效能到团队管理再到绩效管理的全场景能力需求
- 课程均对应明确的能力方向，可直接对应企业培训核心需求进行匹配选用
