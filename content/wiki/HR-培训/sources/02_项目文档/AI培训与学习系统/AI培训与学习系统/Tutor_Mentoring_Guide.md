# SCH学分制导师带教手册 (Tutor/Mentor Guide)

## TL;DR
本手册为SCH学分制新员工带教计划的导师操作规范，定义了三类导师角色，划分了三个带教阶段，明确了导师选拔标准与学分激励机制，用于指导导师完成新员工入职带教，帮助新员工顺利胜任岗位。

---

## 要点
1. **导师角色分类**：共三类，分别适配不同场景：
   - 上司导师：面向大多数新员工，负责日常指导与最终考核录用
   - 大客户带教：面向销售、大客户经理等特定岗位，侧重客户管理、商务谈判等实战隐性经验传授
   - 补强导师：面向阶段考核未达80分的新员工，针对薄弱环节提供专项补辅导
2. **三阶段带教流程**：新员工入职需依次完成三个阶段培训，每阶段考核合格（≥80分）方可进入下一阶段：
   - 阶段一：通用技能培训，目标为融入企业、掌握办公技能，入职首周需完成团队介绍与岗位职责明确，最终考核为通识扫盲考
   - 阶段二：专业知识培训，目标为掌握产品知识、行业标准与业务流程，需完成授课讲解与模拟演练，最终考核为知识测试
   - 阶段三：岗位实操，目标为具备独立上岗能力，需完成实操任务安排、现场带教反馈，最终由导师审核实训报告决定正式录用/终止试用
3. **导师选拔标准**：近一年绩效考核B+及以上、认同公司文化乐于分享、在司服务满1年以上（特殊岗位除外）
4. **学分激励规则**：带教产出可累计学分，学分可用于兑换资源、作为晋升必要条件、参与金牌导师评选：
   | 带教成果 | 可获学分 |
   |----------|----------|
   | 学员通过阶段一 | +2 |
   | 学员通过阶段二 | +3 |
   | 学员通过阶段三并正式录用 | +5 |
   | 学员获评优秀新员工 | 额外+5 |
   学分用途：兑换培训经费/外部课程名额、晋升主管/经理的必要条件（要求累计满20学分）、年度金牌导师评选依据

## 完整内容（引用原始资料）
### 1. 导师制度概述
> 本手册基于SCH“学分制带教计划”制定，旨在规范导师（Tutor/Mentor）的选拔、职责与考核，确保新员工在入职后的三个关键阶段获得有效指导，顺利胜任岗位。

---

### 2. 导师角色定义
#### 2.1 上司导师 (Supervisor Mentor)
> *   **适用对象**：大多数新员工。
> *   **职责**：直接负责新员工的日常工作指导、业务知识传授及绩效评估。
> *   **特点**：既是管理者也是教练，负责“生杀大权”（考核录用）。

#### 2.2 大客户带教 (Key Account Mentor)
> *   **适用对象**：特定岗位（如销售、大客户经理）。
> *   **职责**：侧重于复杂客户关系管理、实地拜访技巧及商务谈判指导。
> *   **特点**：实战经验丰富，侧重于“传帮带”隐性知识。

#### 2.3 补强导师 (Reinforcement Tutor)
> *   **适用对象**：在阶段考核中未达标（<80分）的新员工。
> *   **职责**：针对薄弱环节进行“小灶”式辅导，帮助学员通过补考。
> *   **特点**：耐心、专业知识扎实，具备纠错能力。

---

### 3. 带教流程与导师职责
#### 阶段一：通用技能培训 (General Skills)
> *   **目标**：融入企业文化，掌握通用办公技能。
> *   **导师动作**：
>     *   **入职首周**：介绍团队成员，明确岗位职责（MBO/责任田）。
>     *   **日常**：答疑解惑，观察员工融入情况。
>     *   **考核节点**：辅导员工通过“通识扫盲考”（需≥80分）。若未通过，需进行**导师补强**辅导。

#### 阶段二：专业知识培训 (Professional Knowledge)
> *   **目标**：掌握产品知识、行业标准及业务流程。
> *   **导师动作**：
>     *   **授课**：解读产品资料、标准文件（SOP）。
>     *   **演练**：组织模拟销售或操作演练。
>     *   **考核节点**：评估员工提交的“知识测试”（需≥80分）。若未通过，提供额外辅导。

#### 阶段三：岗位实操 (Practical Operation)
> *   **目标**：独立完成业务任务，具备上岗能力。
> *   **导师动作**：
>     *   **派活**：安排具体的实操任务（如独立拜访客户、完成项目模块）。
>     *   **陪访/旁站**：现场观察员工操作，提供即时反馈（On-the-job Training）。
>     *   **评估**：审核“实训报告”，决定是否正式录用或终止试用。

---

### 4. 导师选拔与激励 (Credit System)
#### 4.1 选拔标准
> *   **绩效要求**：近一年绩效考核在B+及以上。
> *   **价值观**：认同公司文化，乐于分享。
> *   **年资**：在司服务满1年以上（特殊岗位除外）。

#### 4.2 学分激励机制
> *   **带教积分**：
>     *   每带教一名新员工并通过阶段一：+2学分。
>     *   通过阶段二：+3学分。
>     *   通过阶段三并正式录用：+5学分。
>     *   学员获评“优秀新员工”：导师额外+5学分。
> *   **积分用途**：
>     *   兑换培训经费/外部课程名额。
>     *   作为晋升主管/经理的必要条件（如：晋升需积累满20学分）。
>     *   年度“金牌导师”评选依据。

---

### 5. 常见问题处理 (FAQ)
> *   **Q: 学员态度不积极怎么办？**
>     *   A: 及时进行绩效面谈，记录面谈内容。若无改善，按试用期管理规定处理。
> *   **Q: 业务太忙没时间带教？**
>     *   A: 带教是管理者的核心职责之一。可申请指定“副导师”（如资深骨干）分担部分日常指导工作，但考核责任仍在主管。
