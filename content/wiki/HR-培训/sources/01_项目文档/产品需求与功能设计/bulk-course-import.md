# 批量课程导入（Bulk Course Import）
## 摘要
本素材为批量课程导入功能对应的待导入课程源数据，包含两门面向前端开发技术的结构化课程信息，明确了每门课程的标题、简介与分模块知识点内容。

## 关键要点
1. 本次待导入共包含2门技术课程，分别为React基础课程和高级TypeScript课程
2. `React Fundamentals` 课程分为2个模块，覆盖React基础入门、组件相关核心知识点
3. `Advanced TypeScript` 课程分为2个模块，覆盖TypeScript高级类型相关核心知识点

## 课程详情
### React Fundamentals
课程简介：学习React基础内容，包括组件、Hook以及状态管理
#### Module 1: Introduction
- What is React?
- [Environment Setup](https://react.dev/learn/installation)
- First Hello World
#### Module 2: Components & Props
- Functional Components
- Passing Data via Props
- ![Component Lifecycle](/media/lifecycle.png)

### Advanced TypeScript

- Basic Generics

#### Module 2: Conditional Types
- Understanding Extends
