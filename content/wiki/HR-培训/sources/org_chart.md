# 希森美康（中国）组织架构

> [!TIP] TL;DR
> 本页整理自希森美康内部公开组织架构图，为希森美康（SCH）现行正式组织架构，最高管理岗为总经理，下辖16个一级部门/机构，本架构仅包含部门层级与岗位设置，不含人员具体任免信息。

---

## 要点
### 顶层架构
最高负责人为**总经理（希森美康/SCH）**，直接管理16个一级部门/直属机构，一级部门负责人职级从主管到常务副总经理不等：
| 一级部门名称               | 负责人职级       |
|----------------------------|------------------|
| 销售本部                   | 常务副总经理     |
| 市场营销部                 | 高级总监         |
| 客户服务本部               | 高级总监         |
| 学术/应用本部              | 副总经理         |
| BD事业开发部               | BD副总监         |
| 注册法规&品保本部          | 总监             |
| 生化免疫事业部             | 总监             |
| 市场执行部                 | 总监             |
| 财务本部                   | 总监             |
| 人力资源行政部             | 总监             |
