# 培训课程建议（管理能力方向）
## 摘要
本文档整理了面向管理者（重点覆盖新经理群体）的核心重点培训课程清单，同时明确了企业管理类培训的四大核心需求分类，为内部培训体系设计提供课程参考依据。

## 核心重点课程列表
| 课程名称 | 课程编码 | 所属模块 |
| --- | --- | --- |
| 角色转身：新经理如何攻克转型难题 | LDNM101 | 基础管理转型 |
| 新经理的关键职责和能力 | LDNM102 | 管理基础能力 |
| 管理者的时间管理法 | SMSJ101 | 个人效能管理 |
| 4步GET面试技巧 | HRZP101 | 人才选拔技能 |
| 识别团队角色，因才施用 | LDHT101 | 团队管理 |
| 因人而异的激励 | OBMS101 | 员工激励方法 |
| 高效组织会议 | TMEM101 | 会议管理 |
| 绩效管理与目标设定 | LDPM101 | 绩效管理基础 |
| 绩效跟踪与评估 | LDPM102 | 绩效过程管理 |
| 让棘手的绩效面谈不再难谈 | LDPM103 | 绩效沟通 |

## 企业培训核心需求分类
本次梳理的管理类培训核心需求分为四大类，具体如下：
- **管理基础技能**：覆盖角色转型、时间管理相关能力培养
- **团队建设能力**：覆盖面试技巧、团队角色识别相关能力培养
- **绩效管理体系**：覆盖目标设定、绩效跟踪、绩效面谈相关能力培养
- **沟通协作技能**：覆盖会议管理、跨部门沟通相关能力培养
