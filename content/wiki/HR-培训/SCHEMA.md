# HR-培训 维基领域规范

本文件定义 HR-培训（人力资源管理与企业培训）领域维基的结构规范。

## 目录结构

```
wiki/HR-培训/
├── entities/          # 实体 - 人、组织、系统、项目
├── concepts/          # 概念 - 理论、方法、模型
├── summaries/         # 源文件摘要 - 对 raw/HR-培训/ 中源文件的提炼
├── sources/           # 源文件处理记录
├── SCHEMA.md          # 本领域规范
├── index.md           # 领域内容索引
└── log.md             # 领域操作日志

raw/HR-培训/           # 不可变的原始源文件
```

## 核心概念分类

### 实体类型 (entities/)
| 类型 | 示例 |
|------|------|
| 系统/平台 | GLAD学习平台, HR智能小助手 |
| 角色/职位 | HRBP, 培训专员 |
| 项目 | 学分制带教, 企业大学AI化 |
| 方法论 | OKR, KPI, 3P薪酬模型 |

| 类型 | 示例 |
|------|------|
