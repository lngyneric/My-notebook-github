# Claude Agent Skills 自动化“万能公式”操作指南

本指南基于“人人可用的自动化”理念，介绍如何通过简单的步骤将任何 Web 操作转化为 Claude AI 可调用的技能（Skill）。

## 🚀 核心公式

> **浏览器 F12 (Copy cURL) + Skill Creator = 全自动生成 AI Skill**

---

## 🛠️ 实操步骤详解

### 第一步：获取数据源（无需 API 文档）

你不需要后端开发提供的 API 文档，只需要利用浏览器即可获取所需的请求信息。

1.  **打开目标网页**：在 Chrome 浏览器中访问你想要自动化的页面（例如：库存查询页、表单提交页）。
2.  **开启开发者工具**：按 `F12` 或右键点击页面选择“检查” (Inspect)，切换到 **Network** (网络) 标签页。
3.  **触发操作**：在网页上进行一次你想要自动化的操作（例如：点击“查询”按钮）。
4.  **复制请求**：
    *   在 Network 列表中找到对应的请求（通常是 Fetch/XHR 类型）。
    *   右键点击该请求 -> 选择 **Copy** -> 选择 **Copy as cURL (bash)**。

### 第二步：自动化生成 Skill

利用 `Skill Creator`（技能生成器）将 cURL 命令转化为标准的 Skill 结构。

1.  **调用 Skill Creator**：在 Claude/Trae 中，告诉 AI 你要创建一个新技能。
2.  **输入指令**：
    > "请帮我创建一个名为 `[技能名称]` 的 Skill。核心逻辑是以下 cURL 命令，请将其封装为 Python 脚本，并生成对应的 SKILL.md。"
3.  **粘贴 cURL**：将第一步中复制的内容粘贴进去。
4.  **等待生成**：AI 会自动分析请求头、参数、Body，并生成包含 `SKILL.md` 和 `script.py` 的完整文件夹。

### 第三步：安装与使用

1.  **部署 Skill**：将生成的文件夹放入你的 `.trae/skills/` 目录下。
2.  **自然语言调用**：
    *   直接对 AI 说：“帮我查询一下 [参数] 的数据”。
    *   AI 会自动匹配刚才生成的 Skill，运行脚本并返回结果。

---

## 🧩 Skill 结构解析

一个标准的 Skill 包含以下核心部分：

| 文件 | 说明 | 作用 |
| :--- | :--- | :--- |
| **SKILL.md** | 核心说明书 | **YAML 头**：定义技能名称和触发条件（AI 靠这个识别技能）。<br>**正文**：操作指南，告诉 AI 何时以及如何使用脚本。 |
| **script.py** | 执行脚本 | 包含具体的 API 调用逻辑（由 cURL 转换而来），处理数据请求与响应。 |

## 💡 进阶技巧

*   **参数化**：在生成 Skill 时，要求 AI 将 cURL 中的固定值（如查询关键词、日期）提取为 Python 脚本的输入参数，这样技能就通用了。
*   **错误处理**：让 AI 在脚本中增加对 HTTP 错误码（4xx, 5xx）的处理逻辑，提高稳定性。
*   **组合使用**：你可以生成多个小的 Skill（如“查询数据”、“发送邮件”），然后通过自然语言让 AI 将它们串联起来工作。
