## 快速入门（三步上手）

### 第一步：创建看板

1. 登录 [padlet.com](https://padlet.com)
2. 点击 **+ 新建（Make）**
3. 选择模板（白板/画廊/路线图等）或空白看板
4. 命名并开始编辑

### 第二步：添加内容

- 直接 **双击** 看板空白处 → 粘贴文字/图片/链接/文件
- 支持**拖拽**调整位置
- 可添加评论、点赞 reactions

### 第三步：分享协作

| 分享方式 | 操作 |
|---------|------|
| 链接分享 | 点击分享按钮 → 复制链接 → 发送 |
| 二维码 | 生成二维码，学生/家长扫码即可 |
| 权限设置 | 可编辑 / 仅评论 / 仅查看 |

## 核心功能速查

| 功能 | 操作路径 | 说明 |
|------|---------|------|
| 文字/图片/链接 | 双击空白处 | 最基础的发布方式 |
| 视频录制 | + → +12 → 视频录制器 | 免费版最长 2 分钟 |
| 音频录制 | + → +12 → 音频录制器 | 免费版最长 5 分钟 |
| 拍照上传 | + → 相机图标 | 快速拍白板/作业 |
| 屏幕录制 | + → +12 → 屏幕录制器 | 需安装 Chrome 扩展 |
| AI 绘图 | + → +12 → I Can't Draw | AI 根据描述生成图片 |
| AI 朗读 | + → +12 → Talk for Me | AI 生成朗读音频 |
| 文件上传 | + → 上传图标 | 支持 PDF 等文件 |

## 隐私与权限设置

| 权限级别 | 说明 |
|---------|------|
| **Reader** | 仅查看 |
| **Commenter** | 查看 + 评论 |
| **Writer**（默认） | 查看 + 评论 + 发帖 |
| **Moderator** | 审核发帖 |

| 隐私模式 | 说明 |
|---------|------|
| Secret（默认） | 仅链接可见，需登录 |
| Secret - Password | 链接 + 密码 |
| Secret - Log in | 需账号登录 |
| Public | 公开搜索可见 |
